## 2. 功能概览与定位

用结构化数据模型重建计划与复盘体系的任务数据流通，实现用户北极星——**数据像水流：计划月→周→日单向下行，完成凭据单向上行，完成态纯派生**。

用户可见成果：周统筹（固定任务+惯常日自动安排+核心推进目标）→ 日规划（rail 选取🔒+五入口）→ 今日总览（四渠道同实体双视图）→ 复盘（数据视图+趋势统计），全程改名/删除全下游传播、零同步痕迹、零幽灵残留。

## 5. 数据模型（方向，DDL 细节见规格-阶段1）

七张新表 + 适配层，前缀 `flow_`（与冻结区物理隔离，技术栈规范 §9.3）：

| 表 | 职责 |
|---|---|
| `flow_fixed_defs` | 固定任务定义（recurrence 预留 / 惯常日 weekdayMask / 场次目标） |
| `flow_week_instances` | 周任务实例（每周克隆，凭据挂实例，完成态不落库） |
| `flow_day_entries` | 日任务行（统一实体：五入口四渠道，G2 同实体双视图的核心） |
| `flow_vouchers` | 完成凭据池（check/manual/extra 三类同池） |
| `flow_month_goals` / `flow_week_focus` | 月目标 / 周核心推进目标（弱级联） |
| `flow_plan_templates` | 结构化计划模板（复制断链套用） |
| `flow_journals` | 叙述域感想（与任务域零外键零同步） |

## 6. 核心设计

### 6.1 克隆引擎（惰性物化）
访问某周数据时，若该周缺少 `flow_fixed_defs` 对应实例 → 现场克隆生成（标题/类型/目标场次/惯常日来自 def；惯常日非空则同时生成对应 `flow_day_entries` 🔒行）。无定时任务、无后台进程。

### 6.2 派生查询（消灭状态字段）
周实例完成态 = `flow_vouchers`（挂实例的 manual/extra）+（挂其 day_entries 的 check）实时计算；rail 可见性 = 本周实例减去已安排/已完成/已跳过；统计与趋势同源。**任何"完成/消耗"缓存字段出现即违规**（技术栈规范 §4.5）。

### 6.3 来源与传播
`flow_day_entries.source + sourceRef` 创建时直存（weekInstance/template/project/reminder/deferred/manual）。改名/删除发生在源头实体，下游展示时经 sourceRef 取实时值——文字只在源头存一份，天然传播、天然一致。

## 8. 任务拆解（概览，细节在各阶段规格）

**阶段1**：① 0008 迁移七表 ② shared flow 类型 ③ 各仓储 + 单测 ④ 克隆引擎 service + 单测 ⑤ 派生查询 service + 单测 ⑥ flow.ipc 骨架 + preload 桥。

## 9. 验收点（功能级，各阶段规格细化）

- [ ] 改名传播：周统筹改名 → 日规划🔒行、今日总览瞬时跟随（立项 #1/#2）

- [ ] rail 语义：已安排全周隐藏；移除/删除即回 rail；跨天不可重复选取（#20）

## 10. 禁止边界 & 错误降级（承袭上位 §7 三表，按本项目具化）

**禁止边界**：
- 禁止任何形式的"任务行存于 Markdown/自由文本"与文本解析建任务（技术栈规范 §4.1/§4.4）
- 禁止完成/消耗/统计状态缓存字段（§4.5 凭据池派生原则）
- 禁止出处内容推断链（§4.6）
- 禁止 import 冻结区模块 / 复用旧 planParser/planTid/syncPlanTodos/todoSource 逻辑（§9.1）
- 禁止修改已发布迁移脚本；新表只增不改（§4.2）
- 承袭上位：软删除、脱敏日志、禁模态弹窗、token.css 唯一色源、禁云端上传

**错误降级**：
| 场景 | 期望行为 |
|---|---|
| 惰性克隆时 DB 写失败 | 返回 Result 错误 + UI 反馈条，页面以现有数据渲染，不崩 |
| 派生查询异常 | 日志 + 空态展示 + 错误条，禁止兜底写缓存值 |
| 项目适配层读项目模块失败 | 该渠道任务不显示 + 渠道级提示，不影响其它三渠道 |
| 旧冻结区被误 import | 构建期即应失败（阶段1 起冻结区不导出新符号），审查 🔴 打回 |
