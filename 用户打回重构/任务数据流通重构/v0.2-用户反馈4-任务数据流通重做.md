## 二、北极星与铁律（写入规格首章，不可违背）

1. **结构化数据库是任务域唯一真相源**——任务行永不活在 Markdown 里
2. **双通道单向**——计划通道月→周→日→待办只向下流；状态通道凭据只向上汇入池，完成态=纯查询派生，**不存在可脏的"完成状态字段"**
3. **自由文本永不回写**——LLM 只做入口解析（确认式落库）与出口渲染
4. **叙述域与任务域物理隔离**——感想/复盘长文永不参与任务同步
5. **离线优先**——结构化控件永远不依赖网络，LLM 是增强层不是地基

## 五、生命周期状态机

### 周任务实例
```
固定模板 ──周一惰性克隆──→ 周实例[未安排]
                              │
              ┌─────rail选取(手动)─────┐
              │                        ↓
         有惯常日:自动安排       周实例[已安排📅 某日🔒行]
              │                        │
              │        ┌───────────────┼────────────────┐
              │        ↓               ↓                ↓
              │    当日勾选/手动凭据   显式跳过🆓       当日24点未勾
              │        ↓               ↓                ↓
              │    凭据入池→完成✅   skipped(免罪)    回rail(本周可重选)
              │                                           │
              ↓                                           ↓周日24:00
        [多次性: 完成场次≥目标 → ✅]              周结封账[定格未完成]
                                                        │
                                              复盘「转下周」→ 下周一次性周任务
                                              （固定型: 下周克隆全新实例，计数清零）
```

### 日任务（当日清单行）
```
自由行: 当日计划 ──勾选──→ ✅归档(可收勾·实时派生)
         │未完成·次日
         ↓
       自动顺延(计数·拖3天高亮) ↺ …周日封账归档

锁定行(🔒): 惯常自动/rail选取 ──勾选──→ 凭据入池✅
         │次日未勾 ──→ 回rail(不顺延)
         显式跳过 ──→ skipped🆓
         挪动 ──→ 移除+目标日再选取(一步封装)
```

### 完成凭据
```
来源: 勾选todo | 手动标记(日期+备注) | +1场次
性质: 唯一事实记录；可编辑可删 → 派生自动重算（实时派生红利）
消费方(纯查询): 周任务完成态 / 跳过统计 / 复盘视图 / 趋势曲线
```
