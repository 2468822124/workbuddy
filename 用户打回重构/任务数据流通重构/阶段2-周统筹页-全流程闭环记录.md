#### 5.2 InstanceRow 交互细则（事无巨细）
| 元素 | 规则 |
|---|---|
| 完成态显示 | once：完成=✓陶土橙勾；multi：`n/目标` 徽章，达标变实心；跳过=⊘ 灰显+删除线，排清单尾部 |
| 固定徽标 | `origin=fixed` → `[固定·周三]`（weekdayMask→中文星期，多日顿号连接；mask=0 显 `[固定]`）；`origin=temp` 无徽标 |
| 安排状态 | `completion.arrangedCount>0` → 显已安排数📅（本阶段只读展示，安排/移除在阶段3） |
| 改名 | 临时：行内编辑（双击标题或编辑图标）；固定：点击提示「固定任务请在右侧管理区改名」（FIXED_INSTANCE err 的 UI 化，info 反馈条） |
| 手动完成（once） | ✓ 图标按钮 → manualComplete；已 done → 按钮变凭据入口（见下） |
| +1 场次（multi） | → addSession；n/目标实时刷新 |
| 凭据入口 | done 或 doneCount>0 → 「凭据 N」可点 → VoucherPopover：列出（kind 中文：勾选/手动/场次 + occurredAt + note），每条[删][改备注/日期]（兑现 R1 撤销 UI），删/改后完成态实时回退 |
| 跳过 | ⊘ 按钮 → 行内二次确认（「跳过本周？不计未完成」[确认][取消]，禁模态）→ skipInstance |
| 转下周 | 仅**历史周**（weekStart < 本周一）显示 → carryInstance(下一周一)，成功 info 反馈 |
| 删除 | 垃圾桶 → 行内二次确认 → deleteInstance（下游安排行随软删——数据层已编排） |
| 新建临时周任务 | InstanceList 头部 [+ 添加]：标题输入 + kind 选择（一次性/多次×N）→ createTempInstance |

#### 5.3 FocusBlock（周核心推进目标，立项 #26）
- 列表项：○ 未完成 / ● 已完成（手勾 doneAt）；[→ 周任务] 按钮 = **复制断链转周任务**（createTempInstance 同名 once）+ 成功后标「已转」徽章（防重复转：本项已存在本周同名 temp 实例时按钮置灰）
- 添加：手写输入 / 从月目标选取（下拉列当月未关闭月目标，选中带入标题+记录 monthGoalId）
- 月目标改名同步核心区文字 = 弱级联：本月目标更新后，重载 focus 列表即取月目标实时标题（focus.title 存快照，显示时若 monthGoalId 非空→取月目标实时 title；**转出的周任务不跟随**——复制断链）

#### 5.4 FixedDefsPanel（每周固定，立项 #11/#12）
- 新建：标题 + kind（一次性/多次×N）+ 惯常日多选（周一~周日 checkbox → weekdayMask）
- 编辑：改标题（改名同步本周实例标题——服务端已编排，UI 重载即见）/ 改惯常日（**只影响未来克隆**，G5 不追溯，info 提示说明）/ 停用（软删：存量实例保留，本周不再克隆）
- 列表徽标同 5.2 固定徽标

#### 5.5 RailBlock（只读）
- 显示 `weekBoard.rail` 标题列表（已含跳过/完成/排满过滤——阶段1 派生）；空态「本周任务已全部安排 🎉」
- 提示条：「选取安排到某日 → 即将上线（阶段3 日规划页）」（开发期占位文案）

#### 5.6 `/flow/month` 月目标页（立项 #25）
- 月份导航（←→月 + YYYY-MM）
- 目标简表：当月目标列表（滚动显示历史未关闭月的目标：**默认显示当月 + 展开看历史未关闭**）；>5 条时软提示「目标聚焦 3~5 条为宜」（非硬限）
- 动作：添加 / 改名 / 手动关闭（closedAt，关闭后从默认视图退入历史区）/ 删除（软删）
- 无自动结算、无"失败"措辞（未关闭跨月滚动显示）

#### 5.7 周导航与数据装载
- `useFlowWeek(weekStart)`：`weekBoard()` IPC（服务端先惰性物化）；周切换 = 本地周一起止计算（复用 `@shared/period` 的 `getWeekStart/addDays`，**勿自写日期数学**）
- 默认进入 = 本周周一；URL query `?week=YYYY-MM-DD` 支持直达任意周（实测用）

#### 5.8 错误降级（承项目计划 §10）
| 场景 | 行为 |
|---|---|
| weekBoard IPC 失败（含物化写失败） | 页面以错误反馈条 + 空态渲染，不白屏不崩 |
| 任一动作 IPC 返回 err | 顶部反馈条显 error.message，列表状态不脏 |
| 断网/DB 异常 | 同上（本地应用无网络依赖，LLM 未接入） |
| 输入校验 | 标题空/纯空格 → 按钮 disabled + 提示；N 输入 1~99 clamp |
