### 问题① — rail 隐藏机制不足：跨天可重复选取 + 改名后重出【🟡 HIGH bug】

**现象**（场景2/4）：
- 8.11 选取周任务"做周报"→ **当天 rail 隐藏 ✓**；但跳到本周其他天，其他天 rail **仍显示"做周报"** → 可在其他天**再次选取同一周任务**（跨天重复选取、跨天重复生成）。
- 改名"做周报"→"做本周周报"后，原已隐藏的当天 rail 也**重新出现**"做周报"。

**根因**（代码证据）：
- `src/renderer/src/components/planning/CascadeRail.vue:20` 过滤逻辑：
  `activeTasks = tasks.filter(t => !t.consumed && !props.inDraftTexts.has(t.text))`
  隐藏只有两个轴：①`consumed`（完成消耗）②`inDraftTexts.has(text)`（**纯文本**命中，且 `inDraftTexts` 仅含**当日**草稿）。
- `inDraftTexts`（`PlanningView.vue:57`）= `extractTaskTexts(planDraft)`；planDraft = `nextStart`（当日/明日）计划 → **其他天的草稿不含该任务** → 其他天 rail 不隐藏。
- `consumed` 按 F3-1.2 **方案C** 仅在 todo 完成时置位（`listTasksByPeriod` 业务规则3），**选取不置位** → 选取后全周无"已安排"信号。
- 隐藏按**纯文本**，**不认**行内 `<!-- tid:child parent:parentTid -->` 关联 → 改名后子文本"做本周周报"与父任务"做周报"分叉，比对失效 → 当天也重新出现。

**用户已决策修复方向**：✅ **改为"按本周 tid 关联隐藏"**
- 周任务（有 tid）只要本周**任意一天**的日规划里有对应 `parent:{其tid}` 行，就在**全周所有天** rail 隐藏。
- 基于已保存数据派生（非"选取即写库"）→ 无幽灵消耗（F3-1.2 方案C 顾虑不复发）；tid 注释不随改名变化 → **顺带修复改名重出**。
- `consumed`（完成）语义不变，方案C 保留。

**DS 实现提示**（DS 定具体实现）：
- 后端 `listTasksByPeriod`（`plans.ipc.ts`）为每个周/月任务增 `scheduledThisWeek: boolean`（扫本周各 `daily_plan` content 的 `parent:{tid}` 注释；可复用 `planParser.parseTasksWithState` 已返回的 `parentTid`）。

- 单测须覆盖：选取→全周隐藏 / 改名→仍隐藏 / 删子任务行→周任务重现 / 完成 todo→consumed 独立生效。

改名+删行组合同理：`A(aaa)/B(bbb)/C(ccc)` → A 改名 + 删 B 保 C → 实际 `A改名<!--aaa-->\nC<!--bbb-->`（C 应挂 ccc 却挂 bbb）❌

- **主因（回归，第二轮问题① scheduledInPeriod 轴引入）**：`PlanningView.onSavePlan`（`src/renderer/src/views/PlanningView.vue:148-196`）保存日规划**不触发 `loadParentTasks`** → rail `parentTasks`（含后端 `scheduledInPeriod`）冻结在挂载/pick 快照。三轴隐藏（`CascadeRail.vue:20`）中，轴① consumed（后端）+ 轴② scheduledInPeriod（后端，第二轮①新增）均依赖 reload 重算；删子任务保存后仅轴③ inDraftTexts（前端反应式 computed）正确放行，**轴② 卡 true → 周任务仍隐藏**。对比：`pickTask` 末尾有 reload（`usePlanning.ts:313`）、`load()` 有（`PlanningView.vue:111`），**唯独 onSavePlan 漏**。scheduledInPeriod 计算逻辑本身正确（`plans.ipc.ts` listTasksByPeriod + `planParser.ts` collectChildRefs，删行后不含该 tid→false），但**保存路径未调用它**。
- **次因（consumed 卡 true）**：用户先勾选完成日 todo → `todos.ipc.ts:53-59` TODOS_TOGGLE 把周任务行 `[ ]→[x]`（consumed=true，方案C 消耗跟随完成）；删子任务行**不回退** consumed（回退逻辑只在 toggle 取消勾选时触发，`todos.ipc.ts:60-74`）→ 轴①也隐藏周任务。用户"勾选过+全空"= **主因+次因叠加，两因都需修**才能让周任务回 rail。

**修复方向（GLM 给，DS 定实现）**：
- **2a 主因**：`PlanningView.onSavePlan` 末尾补 `await plan.loadParentTasks(curStart.value)`（与 `usePlanning.ts:313` pickTask 对齐）→ rail reload → scheduledInPeriod 重算。注意 onSavePlan 当前是否 async，需改 async 或 .then。

### 问题1 — 数据水流式单向传播（北极星愿景）【🟡 新需求，本轮不修，完整记录】
