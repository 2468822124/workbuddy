## 子项详细记录

### 2.1 D5 软删除详细记录
> ⚠️ **本节经用户澄清 + 截图核实后改判**（2026-08-07）：首轮据源码误判为"非缺陷"，用户补"预期每条 TODO 后有删除键，实际没有"+截图后，定位为真实缺陷。教训见末尾。

**根因**：`Pencil` / `Trash2` 图标未在 `AppIcon.vue` 注册 → 纯图标按钮渲染为空 → 不可见

**关键判断证据**：
1. **详情页确实用了 TaskRow**：`src/renderer/src/views/ProjectDetailView.vue:104-110`
2. **TaskRow 模板含删除+编辑+勾选**：`src/renderer/src/components/project/TaskRow.vue:48-75`
3. **根因——图标未注册**：`src/renderer/src/components/AppIcon.vue:3-17` 注册的图标集中**`Pencil` ❌ 未注册、`Trash2` ❌ 未注册**

**教训**：代码存在 ≠ 渲染可见；图标类组件必须核注册表全链。后续涉及 `<AppIcon>` 的审查，须把"模板用到的 name ⊆ map 已注册"列为硬核项。

### 2.2 E1 测试连接详细记录
**根因**：HTTP 状态码单点校验，未校验响应体

**关键判断证据**：
- **① 仅校验 HTTP 状态码，从不校验响应体（~95%）**
  - `src/main/services/llm.ts:70-77`（`testConnection`）：仅看 `res.ok`，零响应体校验
- **② 为什么"错误但存在的网址"会误报成功**：大量真实网站/CDN对任意 POST 路径返回 **HTTP 200 + HTML 错误页**（soft-404）

**修复**：解析并校验响应体为有效 OpenAI Chat Completion：读 `await res.json()`，校验存在 `choices` 数组且 `choices[0].message.content` 为字符串。

### 2.6 U6 无数据占位详细记录
**根因**：短路条件用 AND + `findActive()` 无日期过滤 → 短路永不触发

**关键判断证据**：
- `const projects = projectRepo.findActive().slice(0, LLM_PROJECT_LIMIT)`——**全局所有进行中项目，无日期过滤**
- `if (done.length === 0 && projects.length === 0)`——只要库里有任意进行中项目 → `projects.length >= 1` → 短路永不触发

**规格缺陷**：本实现是**规格伪代码的逐字拷贝**——规格本身有设计缺陷（把"全局存在进行中项目"误当"当日有项目活动"），需代码 + 规格同步修。

**修复**：短路条件改为**仅看当日完成数** `if (done.length === 0)`
