### U3 模板完整链路

1. 在日规划新建一个至少两项的日模板。
2. 观察创建后的列表、模板名称、项目数和页面反馈。
3. 点击“套用”，先取消确认，确认取消不产生任务。
4. 再次套用，只勾选其中一项，确认目标日期产生一条任务且来源为模板。
5. 编辑模板名称和一项内容，确认已有任务不被改写。
6. 删除模板，先取消，再确认删除；确认历史已生成任务仍保留。
7. 若出现失败，截图必须包含模板表单、按钮、列表和页面内错误文字。

### U4 周核心目标修复回归

1. 创建月目标 `v0.3用户复测月目标`。
2. 在本周核心推进目标中从月目标选取并添加，确认计数增加且标题正确。
3. 再添加手动核心目标，确认第二条也成功。
4. 完成其中一条，再取消完成；删除一条时先取消再确认。
5. 离开周统筹后返回，确认目标、完成状态和来源仍一致。

### U5 复盘统计修复回归

1. 创建一条本周任务并安排到今天。
2. 在日规划完成它，进入复盘趋势。
3. 记录计划总数、完成数、完成率和当天明细。
4. 取消完成、顺延、跳过各至少一次，分别记录统计变化。
5. 刷新页面并切换上一周/下一周，确认统计不回退、不串周。

### U6 导出 JSON

1. 设置 → 数据管理 → 导出 JSON。
2. 在测试专用目录之外选择临时路径，例如桌面 `v0.3-test-backup.json`。
3. 用本地文本编辑器查看 JSON 结构，确认包含月目标、周任务、日任务、模板、感想、项目等业务数据。
4. 确认 JSON、应用日志和截图中没有 API Key 明文、完整用户文件路径或不应外泄的私人内容。

### U7 导入 JSON 与取消保护

1. 先保留当前测试数据和刚才的导出文件。
2. 点击“导入 JSON”，在原生文件选择器中选刚才的备份，先点击取消，确认当前数据不变化。
3. 再次选择备份，确认覆盖提示后继续。
4. 返回月指导、周统筹、日规划、项目和复盘，确认数据恢复且没有重复任务。
5. 使用缺少必需表的 JSON、空对象和非法 JSON 各测试一次，确认页面内有可读错误且原数据不被清空。

### U8 旧入口与错误降级

1. 在地址栏分别访问旧规划入口（若产品提供历史链接），确认重定向到新页面，不加载旧 Markdown 页面。
2. 在设置中清空 Base URL 或输入不可达本地地址，使用虚构 Key 测试连接。
3. 确认失败后任务、项目、复盘仍可使用；没有系统模态框、无限重试、白屏或 API Key 明文。
4. 如执行损坏数据库测试，先关闭应用并完整备份 `E:\workbuddy-test\userData`，只在测试副本中操作，结束后用重置脚本恢复。

### U9 运行环境安全核对

1. 关闭测试程序后确认真实 `%APPDATA%\workbuddy\` 未被修改。
2. 确认 `E:\workbuddy-test\userData` 与真实数据库路径不同。
3. 记录启动、重置和测试过程中的任何乱码、命令行错误、未注册 IPC、数据库错误或数据丢失。
