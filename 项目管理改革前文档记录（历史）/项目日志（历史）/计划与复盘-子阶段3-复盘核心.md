## 实现概要
激活「复盘」为可用功能 + 打通「执行→复盘」数据环：`Review` 类型入 `@shared/types`；`extractDigest` 纯函数（Markdown→摘要纯文本截断）+ vitest 单测 8 例全绿；`reviewRepo`（CRUD + softDelete + `linkedProjectIds` JSON 往返，**无 syncPlanTodos**——复盘不生成 todos）；6 个 `review:*` IPC + preload 桥；ReviewView 激活（默认昨天/`?date=` 预填/按日期+type 加载/保存 create↔update/内联反馈禁模态/防双击）；昨日复盘卡（ToddayView b-rev）：扩展 `useToday` 拉昨日日复盘 → 有则摘要+「查看/编辑」，无则 EmptyState+「写复盘」入口。`EmptyState` 新增默认 slot 支持按钮。无新迁移（0003 子阶段1 已补齐 reviews 治理字段）。
