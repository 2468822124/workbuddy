## 修复明细

### F1 [MED] + F1b — 后台刷新通知链断裂 + newsOk 语义错误
- **文件**：`services/news.ts`, `services/morning.ts`, `composables/useToday.ts`
- **改法**：
  - news.ts: 新增 `sendNewsUpdated()` helper，`refreshNews()` upsert 完成后调用，`getMainWindow().webContents.send('news:updated')`
  - morning.ts: 移除 `morning:done` 发送 + `getMainWindow` 导入（刷新通知统一由 refreshNews 内部发）
  - useToday.ts: `newsOk` 改读 `lastNewsFetchOk` 设置值（`loadAll` 和 `loadNews` 回调内），全失败时 newsOk=false → 热点卡显示「暂无更新点击重试」
- **验证**：grep 确认 `news:updated` 在 news.ts:12 发送；build ✅

### F2 [LOW] — preload news.list 类型
- **文件**：`preload/index.ts`
- **改法**：`Promise<Result<unknown[]>>` → `Promise<Result<NewsItem[]>>`，加 `NewsItem` import
- **验证**：build ✅；去除 useToday 的 `as NewsItem[]`（类型直接一致）

### F3 [LOW] — MORNING_STATUS 缺 inWindow + 死 code
- **文件**：`ipc/news.ipc.ts`, `composables/useToday.ts`
- **改法**：
  - news.ipc.ts: MORNING_STATUS 补算 `inWindow`（nowMin 与 morningStart/End 比较）
  - preload/index.ts: 返回类型加 `inWindow: boolean`
  - useToday.ts: 移除 `morningWindow` ref（模板未用）+ 相关 `morningStart/End` 异步取
- **验证**：build ✅；`useToday` 返回对象不再含 `morningWindow`
