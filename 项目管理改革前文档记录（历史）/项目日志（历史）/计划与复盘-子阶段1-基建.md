## 已知项（GLM 审查注意）
1. **0003 迁移首次运行验证**：headless 环境无法实跑 `runMigrations()`（需要 Electron 启动 DB 连接）。GLM 审查时需在已安装的 0.1.0 环境启动 dev → 检查 `__schema_migrations` version=3 且 `PRAGMA table_info` 确认新列存在。`addColumnIfMissing` 防御了重跑。**此条同 ELF 风险（Electron Only）：仅可 Electron GUI 验证**。
2. **planView/reviewView 保存按钮 disabled**：按 spec 子阶段1 不实现保存；子阶段2/3 激活。
3. **MarkdownEditor 工具栏不适用 readonly 模式**：已按 spec 实现 toolbar = 隐藏（`v-if="toolbar && !readonly"`）。
