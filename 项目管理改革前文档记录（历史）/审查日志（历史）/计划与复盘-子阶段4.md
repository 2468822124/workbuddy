## 4. 错误降级核查（项目计划 §7-C / 规格 §10）
| 场景 | 期望行为 | 实测结论 |
|---|---|---|
| 未配 LLM | 入口 disabled + 去设置，不发包 | ✅ composable checkReady→llmReady=false→disabled+去设置；guide/summarize 首行守卫本地置错不调 ipc；requestChat 纵深守卫 |
| 汇总无数据 | 不调 LLM 返回占位草稿 | ✅ summarizeReview L374 短路返回（不进 requestChat） |
| 模型非 JSON（```json``` 围栏/多余解释） | items=[] / draft 取原文前 1000 字，不崩 | ✅ parseJsonObject 鲁棒解析；调用方降级（§2 #8） |
| 401/403 | 「API Key 无效或已过期，请前往设置检查」 | ✅ LLM_AUTH 映射 |
| 429 | 「请求过于频繁，请稍后再试」 | ✅ LLM_RATE_LIMIT 映射 |
| 5xx | 「AI 服务暂时不可用（status）」 | ✅ LLM_UNAVAILABLE 映射 |
| 网络错 | 「网络连接失败，请检查网络或 Base URL」 | ✅ LLM_NETWORK 映射（fetch catch 非 Abort 分支） |
| 超时 >30s | 「AI 响应超时（>30s），请稍后重试」 | ✅ AbortController + LLM_CHAT_TIMEOUT_MS=30_000 → AbortError→LLM_TIMEOUT |
| 单次不重试 | 无循环/无自动重发 | ✅ requestChat 单次 fetch；IPC handler 无重试；UI 仅手动「重试」按钮（用户触发） |
| 回填安全 | 替换前面板提示「将覆盖当前内容」；用户显式点击；append 非破坏 | ✅ draft-warn 文案到位；textarea 原生 undo 可撤销 replace；append 为拼接 |
