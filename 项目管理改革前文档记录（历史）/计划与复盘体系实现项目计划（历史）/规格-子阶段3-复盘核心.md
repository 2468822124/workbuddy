## 1. 单元目标

激活「复盘」为可用功能 + 打通「执行→复盘」数据环。一句话可演示：**昨日复盘卡（今日总览）显示昨天的日复盘摘要；点「写复盘」→ 复盘页预填昨天 + 日复盘模板 → 写完保存；再进今日总览，昨日复盘卡显示这条摘要。** 复盘 CRUD 全离线可用，不依赖 LLM（LLM 汇总草稿是子阶段 4）。

## 2. 范围

- LLM 复盘自动汇总草稿 / `review:summarizeDraft` 通道（子阶段 4）。

- 周/月复盘跨期统计图表、复盘历史列表页。
- F4 修复（子阶段 2 遗留 LOW，orphan 计数）：本子阶段不强制，DeepSeek 可顺手修 `planRepo.syncPlanTodos` 的 orphan 过滤（见 §10 备注），但不阻断本子阶段。

## 5. 核心设计

### 5.1 Review 类型（`@shared/types`）

```ts
export interface Review {
  id: string
  date: string | null              // 'YYYY-MM-DD'
  type: string | null              // 'daily_review' | 'weekly_review'（与模板 type 对齐；字符串留宽）
  content: string | null           // Markdown 原文
  linkedProjectIds: string[]       // 关联项目（DB 内存 JSON 字符串，repo 层 ↔ 数组）；本子阶段 UI 不暴露，默认 []
  isDeleted: boolean
  deletedAt: string | null
  createdAt: string
  updatedAt: string
}
```

### 5.2 extractDigest 纯函数（`shared/reviewDigest.ts`）

复盘卡摘要：把 Markdown 原文压成一行纯文本前 N 字。纯函数，无 DB/无副作用。

```ts
const MARKDOWN_LINE_RE = /^\s*#{1,6}\s*$|^\s*-{3,}\s*$|^\s*\{\{.*\}\}\s*$|^\s*[-*]\s+\[[ xX]\]\s*$/

/** Markdown → 摘要纯文本。去标题/分隔/占位/空任务行 + 去行内符号 + 截断。空→''。*/
export function extractDigest(content: string, maxLen = 80): string {
  if (!content) return ''
  const kept = content.split(/\r?\n/)
    // 1. 过滤：空行、纯标题行、纯分隔线、模板占位行、空任务行
    .filter(line => line.trim() !== '' && !MARKDOWN_LINE_RE.test(line))
    // 2. 去行内 markdown 符号
    .map(line => line
      .replace(/^\s*#{1,6}\s*/, '')        // 行首标题符
      .replace(/^\s*[-*+]\s+(?:\[[ xX]\]\s+)?/, '') // 列表/任务符
      .replace(/^\s*\d+\.\s*/, '')          // 有序列表符
      .replace(/\*\*|__|~~|`/g, '')         // 强调/代码/删除线
      .replace(/\[([^\]]*)\]\([^)]*\)/g, '$1') // [text](url) → text
      .trim())
    .filter(line => line !== '')
  const joined = kept.join(' ').replace(/\s+/g, ' ').trim()
  if (!joined) return ''
  return joined.length > maxLen ? joined.slice(0, maxLen) + '…' : joined
}
```

- 复盘模板结构（子阶段1 seed）：`# 🌙 日复盘 · {{date}}` + 多 `## section` + `- ` 列表 + `{{progress}}` 占位。extractDigest 过滤掉标题/占位/空任务行，保留用户填的实质内容首段。
- 非法/空/全占位输入 → `''`（UI 据此显示「昨日已复盘」但摘要为空，或按无内容处理），不抛。

### 5.3 reviewRepo（`db/repositories/reviewRepo.ts`，镜像 planRepo 但**无 syncPlanTodos**）

方法：
- `findAll(opts?: { from?; to?; type? })` —— `WHERE isDeleted=0` + 可选日期/type 过滤，`ORDER BY date DESC, createdAt DESC`。
- `findById(id)` —— `isDeleted=0` 过滤。
- `findByDate(date, type?)` —— `WHERE date=? AND isDeleted=0`（+可选 `type=?`）`ORDER BY createdAt DESC LIMIT 1`（最新一条）。
- `create(data)` —— 插入；`linkedProjectIds` 存 `JSON.stringify(data.linkedProjectIds ?? [])`。
- `update(id, data)` —— 更新 content/type/date + `linkedProjectIds`（数组→JSON）+ updatedAt。
- `softDelete(id)`。
- `rowToReview`：`linkedProjectIds` 字符串 → 数组（`JSON.parse`，异常→`[]`）；`isDeleted` 布尔↔0/1。

id 生成：`import { randomUUID } from 'node:crypto'`（**静态 import**；不新增 require）。

> 复盘**不解析**、**不生成 todos**、**无 sync**。CRUD 即终。这是与 planRepo 的唯一结构差异。

### 5.4 IPC（`reviews.ipc.ts` + `@shared/ipc` 加 `REVIEW_*`）

沿用 ok/err 信封 + logger（**禁记 review.content 明文**）。**无 runSync**（不解析）。

| 通道 | 入参 | 返回 data |
|---|---|---|
| `REVIEW_GET` | `{ id }` | `Review \| null` |
| `REVIEW_LIST` | `{ from?, to?, type? }` | `Review[]` |
| `REVIEW_BY_DATE` | `{ date, type? }` | `Review \| null`（该日期+type 最新一条） |
| `REVIEW_CREATE` | `{ date, type?, content, linkedProjectIds?, templateId? }` | `Review` |
| `REVIEW_UPDATE` | `{ id, content, date?, type? }` | `Review` |
| `REVIEW_DELETE` | `{ id }` | `{ ok }`（软删） |

- `REVIEW_BY_DATE` 支持 type 过滤：昨日复盘卡传 `{date: 昨天, type: 'daily_review'}`；ReviewView 传 `{date, type: selectedTpl.type}`。
- 失败信封：`err('INVALID'/'NOT_FOUND'/'INTERNAL', msg)`；logger 仅记异常 `e`，不含 content。

### 5.5 ReviewView 激活（变动 `ReviewView.vue`，镜像 PlanView 子阶段2 模式）

- **默认日期 = 昨天**（复盘 = 回顾已结束的一天；与「昨日复盘卡」语义一致）。路由 `?date=YYYY-MM-DD` 优先（从昨日复盘卡「写复盘/查看」进入预填昨天）。
- 顶部：`<input type="date">`（默认昨天或 query.date）；变更 → 按日期+当前模板 type 加载。
- 加载：`api.reviews.byDate({date, type: selectedTpl.type})` 有则载入 content/type；无则载入选中模板内容。
- 主体：MarkdownEditor（不变）。
- 底部：**「保存」按钮启用**（替换子阶段1 disabled）。有 `currentReviewId` 则 `REVIEW_UPDATE`，否则 `REVIEW_CREATE`。
- 反馈（**内联，禁模态**）：`✅ 已保存`（复盘不生成待办，无「生成 N 条」）；失败 `❌ 保存失败：{msg}`。
- 保存 loading 态防双击。
- 日期读取：`onMounted` 读 `route.query.date`；无则昨天。

### 5.6 昨日复盘卡衔接（变动 `useToday.ts` + `TodayView.vue`）

**useToday 扩展**（单一数据入口，保持内聚）：
- 新增 `yesterdayReview = ref<Review | null>(null)`。
- 昨天日期：`const yd = new Date(); yd.setDate(yd.getDate() - 1); const yesterday = yd.toISOString().slice(0,10)`。
- `loadAll()` 的 `Promise.all` 增加一项 `api.reviews.byDate({ date: yesterday, type: 'daily_review' })`；ok 且 data → `yesterdayReview.value = data`，否则 `null`。
- return 增加 `yesterdayReview`。

**TodayView `b-rev` 卡**（替换现有 `<EmptyState>`）：
- 有 `yesterdayReview` → 显示摘要：`extractDigest(yesterdayReview.content ?? '')`（若摘要为 `''`，显示「昨日已复盘」）；底部「📝 查看/编辑」链接 → `router.push('/review?date=' + yesterday)`。
- 无 `yesterdayReview` → `<EmptyState icon="BookOpen" title="昨日未复盘" description="回看昨天，温柔地总结。" />` + 「📝 写复盘」按钮 → `router.push('/review?date=' + yesterday)`。
- 入口用文字链接（token 色，镜像子阶段2 `.plan-link`），**不引入新图标**（BookOpen 已注册；规避子阶段1 F1 教训）。

## 10. 禁止边界 & 错误降级（承袭项目计划 §7-B/§7-C，本子阶段具化）

**禁止边界**：
- **日志禁输出 review.content 正文**与 API Key 明文（logger 仅记异常/计数）。
- 删除一律软删除（review.softDelete）。
- 禁业务数据上云；禁阻断式模态弹窗（保存反馈用内联状态行）。
- **静态 import**：`reviewRepo` 用 `import { randomUUID } from 'node:crypto'`；不得新增 `require(...)`。
- token.css 唯一色源，组件内禁硬编码 hex；**昨日复盘卡入口用文字链接（token 色），不引入新图标**（承袭子阶段1 F1 + 子阶段2 教训——BookOpen 已注册即可，勿新增）。
- `extractDigest` 放 `@shared/`（非 main/services）：renderer 昨日复盘卡需直接 import，`@shared` 为共享层不跨 bundle 边界。

**错误降级**：
- **昨日复盘拉取失败**（byDate 抛错/DB 异常）：`yesterdayReview=null` → 卡显示「无复盘」EmptyState 态，不崩、不白屏。
- **extractDigest 异常**：纯函数内不抛（空/非法→`''`）；UI 据空串显示「昨日已复盘」或 fallback。
- **保存失败**：内联 `❌ 保存失败：{msg}`，不丢编辑器内容（用户可重试）。
- **DB 锁定/损坏**：沿用全局安全模式（只读 + Toast）。

> **F4 备注（子阶段2 遗留 LOW，非本子阶段强制）**：`planRepo.syncPlanTodos` 的 `orphanTodoIds` 含已软删 todo（`planRepo.ts:183`）。DeepSeek 可在本子阶段顺手修（`orphanTodoIds` 过滤 `todoRepo.findById(x)?.isDeleted===false`），或留维护期 CR。修与不修均不阻断本子阶段验收。
