# 阶段 0 视觉规格 — WorkBuddy 手帐风设计系统

> **产出方**：GLM（项目经理）
> **消费方**：DeepSeek（阶段 1+ 实现 UI 的唯一视觉基准）
> **配套样张**：`今日总览-样张.html`（同目录，token 的活样例）
> **状态**：待用户确认视觉方向（M0 门禁）

---

## 0. 目的与原则

锁定 WorkBuddy「手帐风」视觉方向，消除「95% 还原度」的主观不确定性。

**四条铁律**：
1. **禁纯黑 `#000` / 纯白 `#FFF` 高对比**；文字用暖深棕灰，表面用暖白。
2. **禁科技蓝**；主色为陶土暖橙。
3. **拒绝模板感**：用 Bullet-Journal 圆点纸隐喻 + 不对称 Bento + 克制彩色，做出有性格的界面。
4. **呼吸感**：宽松间距、略宽字距、大圆角、柔阴影。

## 1. 设计理念

| 隐喻 | 落地 |
|---|---|
| 纸质手帐 | 暖米底色 + 极淡圆点网格（bullet journal dots） |
| 陪伴者 | 陶土暖橙强调；圆角与柔阴影降低压迫 |
| 克制彩色 | 仅分类标签 / 状态用色，主体保持纸面素净 |
| 手写温度 | 略宽字距 + 圆角线条图标（Lucide） |

## 7. 图标规范

- **库**：[Lucide](https://lucide.dev)（圆角线条，风格统一）。
- **尺寸**：默认 `18px` / `20px`；标题区 `20px`；mini `14px`。
- **描边**：`stroke-width: 1.75`，比默认略细，更柔和。
- **颜色**：继承当前文字色；交互图标用 `--text-muted` → hover `--accent`。
- **落地**：Vue 工程用 `lucide-vue-next`，按需引入，不要全量打包。

常用图标建议：`layout-grid`(总览)、`folder-kanban`(项目)、`library`(知识库)、`dumbbell`(运动)、`settings`、`sparkles`(logo/Agent)、`sun`(问候)、`check-square`/`circle`(待办)、`newspaper`(热点)、`inbox`(交接)、`lightbulb`(灵感)、`book-open`(复盘)、`plus`、`refresh-cw`。

## 8. 动效规范

```css
--ease-out: cubic-bezier(.22,1,.36,1);   /* 主力，温和回弹 */
--ease-soft: cubic-bezier(.4,0,.2,1);
--dur-fast: 140ms;
--dur-base: 220ms;
--dur-slow: 360ms;
```
- **只动合成友好属性**：`transform` / `opacity`；禁动 `width/height/top/left/padding`。
- 卡片悬停：`translateY(-2px)` + 阴影升级，`--dur-base --ease-out`。
- 勾选完成：划除线 + 文字褪色，`--dur-base`。
- Agent 心跳点：`opacity` 呼吸，`--dur-slow` 无限循环。
- **`prefers-reduced-motion: reduce`** 时：关闭所有位移动画与循环，仅保留瞬时颜色过渡。

## 9. 组件规范

### 9.1 卡片 Card
- 容器：`bg-surface` + `radius-xl(20px)` + `shadow-sm` + `1px solid border-soft` + 内边距 `space-6`。
- 标题行：`flex` 两端；左 = 标题(`fs-h1`/`fw-semibold`/`text-strong`) + 计数 chip；右 = 次操作图标(`text-muted`)。
- 可交互卡片 hover：`shadow-md` + `translateY(-2px)`。

### 9.2 按钮 Button
| 类型 | 外观 | 状态 |
|---|---|---|
| 主按钮 | `bg:accent` / `text-on-primary` / `radius-md` / `padding: 10px 16px` / `fw-medium` | hover→`accent-hover`；press→`accent-press`；focus→`accent-ring` 2px ring；disabled→opacity .5 |
| 次按钮(ghost) | 透明 / `text-base` / `1px border-soft` | hover→`bg-hover` |
| 图标按钮 | 透明 / 36×36 / `radius-md` | hover→`bg-hover`，图标转 `accent` |

### 9.3 输入框 Input
- `bg-sunken` + `radius-md` + `1px border-soft` + 内边距 `10px 12px` + `fs-body`。
- focus：边框→`accent`，ring→`accent-ring`，**禁用纯黑/蓝 outline**。
- placeholder：`text-faint`。

### 9.4 勾选 Checkbox
- 20×20，`radius-sm`，未选 `border` 描边 + `bg-surface`；选中 `bg:accent` + 白色 `check` 图标。
- 选中态同行内容：`text-muted` + `line-through`，`--dur-base` 过渡。

### 9.5 标签 Chip / Tag
- `radius-pill`，`fs-caption`，`padding: 3px 10px`，`tracking-wide`。
- 分类标签：底 = 分类色 @12%，字 = 分类色。
- 计数 chip：底 `accent-soft`，字 `accent`。

### 9.6 空状态 Empty State
- **不是「坏掉」，是「敬请期待」**：居中 doodle 图标(Lucide, 44px, `accent` @ 35% 透明) + 一句标题(`text-base`/`fw-medium`) + 一句说明(`text-faint`/`fs-small`)。
- 可在卡片底色上叠极淡 `accent-soft` 圆形背景增加温度。

### 9.7 侧边栏导航 Nav
- 宽 220px，可折叠至 64px（仅图标）。
- 项：`radius-md` + `padding: 10px 12px`；图标 20px + 文字。
- **激活项**：`bg:accent-soft` + `text:accent` + 左侧 3px `accent` 竖条。
- 禁用项（即将上线）：`text-disabled` + 角标「敬请期待」mini chip。
- 底部 Agent 状态卡：呼吸绿点 + 「Agent 已唤醒」+ 最近更新时间。
- **窄窗折叠**：< 1180px 时折叠为 **64px 图标轨道**（仅图标居中，隐藏文字/标签/角标），**不要直接隐藏**侧边栏。

### 9.8 问候与称呼（动态）
- Hero 问候语 = `{{时段问候}}，{{称呼}}`，二者均动态：
  - **时段问候**：按当前时间取「早安/午安/晚安」（主进程计算后传入）。
  - **称呼**：来自 **设置 → 称呼/昵称**（settings 表），默认空时回落「朋友」。
- 称呼为普通文本，**不可执行**（防 XSS：渲染时文本转义，禁用 v-html）。
- 样张演示：`contenteditable` + `localStorage` 模拟；真实应用一律走 settings 配置项，不在 Hero 直接编辑。

## 10. Bento 布局规范（今日总览）

```
grid-template-columns: repeat(4, 1fr);
grid-auto-rows: minmax(150px, auto);
gap: 20px;

grid-template-areas:
  "hero     hero     hero     hero"
  "todo     todo     hot      hot"
  "todo     todo     hot      hot"
  "handover handover idea     review";
```
| 卡片 | area | 跨度 | Day-1 |
|---|---|---|---|
| 问候 Hero | `hero` | 4 列 | 实（问候+日期+摘要+新待办按钮） |
| 今日待办 | `todo` | 2 列 × 2 行 | 实数据 |
| 今日热点 | `hot` | 2 列 × 2 行 | 实数据（含对话搜索输入条预览） |
| 交接事项 | `handover` | 2 列 × 1 行 | 实数据 |
| 今日灵感 | `idea` | 1 列 | 空状态 |
| 昨日复盘 | `review` | 1 列 | 空状态 |

**响应式（窗口自适应 —— 桌面应用窗口可任意缩放，必须全自适应）**：
- 一切宽度用流式单位（`fr` / `minmax` / `clamp` / `%`），**禁止固定像素列宽**；间距用 `clamp()` 随窗宽伸缩。
- 主内容区 `max-width: 1500px` 居中，超宽屏两侧留白，避免拉伸稀疏。
- 断点（与样张一致）：
  - `> 1180px`：侧边栏 220px + Bento 4 列（默认形态）。
  - `≤ 1180px`：侧边栏折叠为 **64px 图标轨道**（见 §9.7）；Bento 仍 4 列。
  - `≤ 980px`：Bento 重排 2 列（hero/todo/hot/hand 各占满宽，灵感+复盘并排）。
  - `≤ 720px`：Bento 单列纵向；侧边栏隐藏（桌面最小窗兜底）。
- **平滑过渡**：窗口拖拽缩放过程中布局连续变化，**不得出现横向滚动条**（`overflow-x:hidden` 兜底 + 内容 `min-width:0`）。

## 11. 落地指引（Vue 工程）

1. 新建 `src/styles/tokens.css`，把第 2~8 节所有 `--*` 变量写入 `:root`，**单一真相源**。
2. `main.ts` 引入 `tokens.css`；组件只引用 token，**禁止硬编码 hex**（仅 tokens.css 出现色值）。
3. 全局底色 + 圆点纸纹理放 `body`：
   ```css
   body {
     background-color: var(--bg-app);
     background-image: radial-gradient(circle, rgba(122,100,76,.05) 1px, transparent 1px);
     background-size: 22px 22px; /* bullet journal dots */
   }
   ```
4. 字体在 `index.html` 引入 Google Fonts `Noto Sans SC`（weights 400/500/600/700），`font-display: swap`。
5. 图标用 `lucide-vue-next`，封装一个 `<AppIcon name="..." />` 统一尺寸/描边。
6. 卡片 / 按钮 / 输入 / 标签 / 空状态各抽一个基础组件（`BaseCard` 等），遵循第 9 节状态机。
