# 模板文件夹说明

> **上位文件**：`规范类/文档治理总纲.md`、`规范类/阶段闭环门禁规则.md`。命名/位置约定见总纲 §5。
> **模板定位（改革后）**：模板只服务**全流程闭环记录文档内各环节**的书写（套格式续写），不是独立文档。历史环节是粘贴保真，不套模板（见 `改革计划.md §四`）。

## 落点对照（全流程单文档）

| 闭环 | 全流程文档落点 | 用到的模板环节 |
|---|---|---|
| **构建期**（子阶段） | `开发阶段/vX-{功能名}/vX-{unit}-{名}-全流程闭环记录.md` | 规格(计划部分) → 实现日志(项目日志部分) → 审查/复审(审查部分) |
| **用户实测**（反馈） | `用户实测阶段/vX-{功能名}-实测/vX-用户反馈{N}-{简述}-全流程闭环记录.md` | 用户实测反馈部分（全程） |
| **维护期 CR** | `变更开发/vX-{功能名}/CR-{NNN}-{简述}-全流程闭环记录.md` | 变更请求(变更请求部分) → 变更日志(变更日志部分) → 审查/复审(审查部分) |
| **功能级项目计划** | `开发阶段/vX-{功能名}/项目计划.md`（独立活文档，10 prompt 产出） | 项目计划部分（功能级粒度） |

## 维护方与流程

- **GPT**：项目计划部分（规格/功能计划）、审查部分、变更请求部分、用户实测反馈部分的诊断与编排
- **DeepSeek**：项目日志部分（实现日志）、变更日志部分（CR 实现）、用户实测反馈部分的修复记录
- 启动 prompt 与完整链路见 `用户prompt/00-开发单元闭环Prompt使用说明.md`（功能立项 10；构建期 01–05；用户实测 06/07；维护期 CR 08/09）
- 变更闭环规则见 `规范类/变更闭环规则.md`；门禁规则见 `规范类/阶段闭环门禁规则.md`

> 模板服务「后续新增环节」的书写；全流程文档的历史环节为旧文档原样粘贴，不套模板。
