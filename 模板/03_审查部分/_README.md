# 审查部分模板

本分类包含审查和复审环节使用的模板。

## 模板列表
- `审查部分编写模板.md`：GPT 审查/复审的标准记录结构

## 维护方
- **GPT**：审查与复审环节；新复审直接追加到对应全流程文档，不再创建 `审查日志/` 文件夹

## 使用时机
- 每个阶段实施完成后进行审查时
- 变更请求实现后进行审查时
- 需要构建期复审或用户实测轮次 `ReviewN` 复审时

## 说明
本模板服务于"新增"的审查部分书写。对于历史阶段，审查内容直接从旧文档原样粘贴到全流程闭环记录文档中，不套用本模板。

## 用户实测轮次复审

用户反馈修复复审使用 `用户prompt/05-gpt复审.md`，输入轮次唯一全流程闭环文档绝对路径和 `ReviewN`。逐条核对 `FixN` 修复要求、原始失败场景、技术栈边界、越界改动和新引入问题，并把结论追加回同一文档；通过后创建同轮下一份测试计划，不直接宣称用户验收闭环。
