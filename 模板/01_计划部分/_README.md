# 计划部分模板

本分类包含项目启动和规格定义阶段使用的模板。

## 模板列表
- `项目计划部分编写模板.md`：用于制定阶段规格，是 DeepSeek 实现的唯一依据

## 维护方
- **GPT**：负责项目计划的编写和维护

## 使用时机
- 启动新开发阶段时
- 定义新功能规格时
- 制定维护期变更请求时

## 说明
本模板服务于"新增"的计划部分书写。对于历史阶段，计划内容直接从旧文档原样粘贴到全流程闭环记录文档中，不套用本模板。

## 与用户实测计划的区别

本分类的“项目计划部分”用于构建期规格和功能级立项，不是用户实测计划。开发完成且所有开发单元达到 `✅开发闭环` 后，由 GPT 使用 `模板/05_实测部分/项目测试计划模板.md` 创建 `R<N>-<n>` 测试计划；所有活跃 R 轮次关闭后，再用同一模板创建独立 `G1` 版本级整合计划。两类计划都定义 GPT 与用户范围、共同核心链路、测试点 ID 和证据落点。
