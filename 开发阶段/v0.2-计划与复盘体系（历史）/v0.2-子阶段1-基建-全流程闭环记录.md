## 5. 核心设计

### 5.1 迁移 `0003_plan_review_governance`（幂等）

- 导出 `init003(): void`，注册：`{ version: 3, name: '0003_plan_review_governance', up: init003 }` 于 `migrate.ts` 的 `migrations[]`。
- **幂等写法**：SQLite `ALTER TABLE ADD COLUMN` 无 `IF NOT EXISTS`，故实现 `addColumnIfMissing(table, col, defn)` 辅助函数——先 `PRAGMA table_info(table)` 查列是否存在，再决定是否 `ALTER`。索引用 `CREATE INDEX IF NOT EXISTS`。确保部分应用/重跑不报错。
- `init003` 内部用 `getDb()`（不自行开事务；`runMigrations` 已包事务）。

### 5.2 templateRepo（沿用 `todoRepo` 对象字面量 + prepared + `RETURNING *` 模式）

方法：
- `findAll(type?: TemplateType): Template[]` — `WHERE isDeleted=0`，可选 `AND type=?`，`ORDER BY type, name`。
- `findById(id): Template | undefined`
- `findByType(type): Template[]`
- `findDefaultByType(type): Template | undefined` — `isDefault=1 AND isDeleted=0`。
- `upsert(data): Template` — 有 `id` 则 `INSERT ... ON CONFLICT(id) DO UPDATE`（或先查后更/插），回填 `updatedAt`；`isDefault`/`isDeleted` 布尔↔0/1 映射。
- `softDelete(id): boolean` — `UPDATE ... SET isDeleted=1, deletedAt=?, updatedAt=? WHERE id=? AND isDeleted=0`；**默认模板禁删**（IPC 层拦截，见 7）。
- `seedDefaults(): void` — **幂等**：按 `name`（或固定 `id`）检查是否存在，缺则插入 3 条默认模板（§5.4）；已存在不覆盖用户改动。

id 生成：`import { randomUUID } from 'node:crypto'`（**静态 import**，勿用内联 `require('crypto')`）。

### 5.3 MarkdownEditor.vue（适度编辑器，非 WYSIWYG）

- **Props**：`modelValue: string`（v-model）；`readonly?: boolean=false`；`placeholder?: string`；`toolbar?: boolean=true`；`showPreview?: boolean=true`。
- **Emits**：`update:modelValue`。
- **结构**：`<textarea>`（源码，绑定 modelValue）+ 预览面板（`marked(modelValue, {gfm:true})` → `DOMPurify.sanitize(html)` → `v-html`）；工具栏按钮（粗体/斜体/标题/任务/列表/链接）在光标处插入对应 Markdown 语法。
- **任务列表**：marked GFM 将 `- [ ]`/`- [x]` 渲染为 `<input type=checkbox disabled>`；预览态只读。
- **样式**：手帐风，全部用 `token.css` 变量（`--bg-*`/`--text-*`/`--r-*`/`--s-*` 等），**组件内禁硬编码 hex**；编辑/预览左右分栏，窄窗可堆叠或切 tab。
- **XSS**：所有预览 HTML 必须经 `DOMPurify.sanitize` 后再 `v-html`。

## 6. 数据模型变更

**新迁移 `0003_plan_review_governance`**（DDL；`addColumnIfMissing` 包装 `ALTER`，索引 `IF NOT EXISTS`）：

```sql
-- plans：补 isDeleted/deletedAt/updatedAt（createdAt 已存在）
ALTER TABLE plans     ADD COLUMN isDeleted INTEGER NOT NULL DEFAULT 0;
ALTER TABLE plans     ADD COLUMN deletedAt TEXT;
ALTER TABLE plans     ADD COLUMN updatedAt TEXT NOT NULL DEFAULT '';

-- templates：补 isDeleted/deletedAt/createdAt/updatedAt（isDefault 已存在）
ALTER TABLE templates ADD COLUMN isDeleted INTEGER NOT NULL DEFAULT 0;
ALTER TABLE templates ADD COLUMN deletedAt TEXT;
ALTER TABLE templates ADD COLUMN createdAt TEXT NOT NULL DEFAULT '';
ALTER TABLE templates ADD COLUMN updatedAt TEXT NOT NULL DEFAULT '';

-- reviews：补 createdAt/updatedAt/isDeleted/deletedAt（原仅有 id/date/type/content/linkedProjectIds）
ALTER TABLE reviews   ADD COLUMN createdAt TEXT NOT NULL DEFAULT '';
ALTER TABLE reviews   ADD COLUMN updatedAt TEXT NOT NULL DEFAULT '';
ALTER TABLE reviews   ADD COLUMN isDeleted INTEGER NOT NULL DEFAULT 0;
ALTER TABLE reviews   ADD COLUMN deletedAt TEXT;

CREATE INDEX IF NOT EXISTS idx_plans_date     ON plans(date)     WHERE isDeleted=0;
CREATE INDEX IF NOT EXISTS idx_reviews_date   ON reviews(date)   WHERE isDeleted=0;
CREATE INDEX IF NOT EXISTS idx_templates_type ON templates(type) WHERE isDeleted=0;
```

- **Day-1 启用**：是（本子阶段第一步即执行）。
- **向后兼容**：纯加列（`ADD COLUMN ... DEFAULT`），存量 0.1.0 库（`__schema_migrations` version=2）平滑升级到 3，既有数据不动。
- **shared 类型**（`@shared/types`）：
  ```ts

  export interface Template {
    id: string

    type: TemplateType | null
    content: string | null
    isDefault: boolean
    isDeleted: boolean
    deletedAt: string | null
    createdAt: string

  ```
  （`plans`/`reviews` 的 TS 接口在本子阶段可一并补齐于 `@shared/types`，供子阶段 2/3 用；字段对齐迁移后表结构。）

## 7. IPC 契约（新增通道）

沿用 `todos.ipc.ts` 模式：`import { IPC, ok, err } from '@shared/ipc'`；`registerTemplatesIpc()`；`ipcMain.handle`；`try/catch` + `logger.error` + `err('INTERNAL'/'NOT_FOUND'/'INVALID', msg)`；返回 `ok(data)`。**logger 不得输出模板 `content` 正文**。

`@shared/ipc` 的 `IPC` 新增（通道名沿用 `domain:action` 风格）：

| 通道常量 | 通道名 | 入参 | 返回（信封内 data） | 说明 |
|---|---|---|---|---|
| `IPC.TEMPLATES_LIST` | `templates:list` | `{ type?: TemplateType }` | `Template[]` | 排除软删；可选 type 过滤 |
| `IPC.TEMPLATES_GET` | `templates:get` | `{ id: string }` | `Template \| null` | |
| `IPC.TEMPLATES_UPSERT` | `templates:upsert` | `Template`（无 id 则内部生成） | `Template` | 新增/编辑；校验 `type` 合法 |
| `IPC.TEMPLATES_DELETE` | `templates:delete` | `{ id: string }` | `{ ok: true }` | 软删；**默认模板（isDefault=1）禁删** → `err('INVALID', '默认模板不可删除')` |

注册：`ipc/index.ts` 的 `registerAllIpc()` 加 `registerTemplatesIpc()`。
Preload 桥：沿用 `window.api.todos.*` 模式，暴露 `window.api.templates.{list,get,upsert,delete}`（具体 preload 文件以现有桥位置为准）。
