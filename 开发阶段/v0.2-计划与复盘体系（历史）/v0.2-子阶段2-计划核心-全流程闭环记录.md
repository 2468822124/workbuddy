## 1. 单元目标

激活「计划」为可用功能：写计划 → 保存 → 自动解析 `- [ ]` → 生成 todos（幂等）→ 流入今日待办卡。一句话可演示：**选今天、写日计划（含 `- [ ]` 任务）、保存 → 今日待办卡出现这些任务；改计划再存不重复建；在待办卡勾选完成后再存，完成态保留。**

## 5. 核心设计

### 5.1 Plan 类型（`@shared/types`）

```ts
export interface Plan {
  id: string
  date: string | null              // 'YYYY-MM-DD'
  type: string | null              // 'daily_plan' | 'weekly_plan'（与模板 type 对齐；字符串留宽）
  content: string | null           // Markdown 原文
  generatedTodoIds: string[]       // 解析生成的 todo id（DB 内存 JSON 字符串，repo 层 ↔ 数组）
  templateId: string | null
  isDeleted: boolean
  deletedAt: string | null
  createdAt: string
  updatedAt: string
}
```

### 5.2 planParser（纯函数，`services/planParser.ts`）

```ts
const TASK_RE = /^(\s*)[-*]\s+\[\s\]\s+(.+?)\s*$/   // 未勾选任务行

/** 提取所有未勾选任务行文本（去空白）。纯函数，无 DB/无副作用。*/
export function parseTasks(markdown: string): string[] {
  if (!markdown) return []
  const out: string[] = []
  for (const line of markdown.split(/\r?\n/)) {
    const m = line.match(TASK_RE)
    if (m) out.push(m[2].trim())
  }
  return out
}
```

- 只提取 `- [ ]` / `* [ ]`；**不**提取 `- [x]`（已勾选）。
- 缩进容错（行首任意空白）。
- 非法/空输入 → 返回 `[]`，不抛。

### 5.3 幂等同步（`planRepo.syncPlanTodos(planId)`，DB 操作）

**算法**（承袭项目计划 §6.2）：
```
1. 读 plan（含 content、generatedTodoIds、date）
2. parsed = parseTasks(plan.content)
3. existingTodos = todoRepo.findByIds(JSON.parse(plan.generatedTodoIds||'[]'))  // 排除软删
4. 按 content 建索引 available = Map<content, todo[]>（每个 todo 可被复用一次）
5. resultIds = []
   for task in parsed:
       const pool = available.get(task)
       if (pool && pool.length) { reuse = pool.shift(); resultIds.push(reuse.id) }   // 复用：保留其 status/completedAt
       else { t = todoRepo.create({ id: randomUUID(), content: task, status:'todo',
                planDate: plan.date, projectId: null, isDeleted:false, deletedAt:null, completedAt:null })
              resultIds.push(t.id) }
6. plan.generatedTodoIds = resultIds；planRepo 更新 plan（回填 updatedAt）
7. 「残留 todo」= 旧 generatedTodoIds 中不在 resultIds 的（用户删了某 `- [ ]` 行）→ **不软删**，仅由 repo 返回 { plan, orphanTodoIds } 供 UI 提示
```

- **复用即保留完成态**：被复用的 todo 若已 `done`，不重置（不传 status → create 不触发；复用路径不改 status）。
- **不自动软删残留**：防误删（用户可能只是临时改文档）。UI 提示「N 条任务已移出计划，对应待办仍保留，可在项目管理清理」。
- 解析/同步 `try/catch`：异常 → **保原文（plan.content 已先存）**、跳过同步、返回 `{ synced: false, error }`，不崩溃（§10 降级）。

> 顺序：保存计划时**先**写 plan.content（确保不丢），**再** `syncPlanTodos`。

### 5.4 planRepo（`db/repositories/planRepo.ts`，沿用 todoRepo/templateRepo 模式）

方法：
- `findAll(type?)` / `findByDate(date)` / `findById(id)` —— `WHERE isDeleted=0`。
- `create(data)` —— 插入；`generatedTodoIds` 存 `JSON.stringify(data.generatedTodoIds||[])`。
- `update(id, data)` —— 更新 content/type/date/templateId + `generatedTodoIds`（数组→JSON）+ updatedAt。
- `softDelete(id)`。
- `setGeneratedTodoIds(id, ids)` —— 同步回填专用（内部用）。
- `syncPlanTodos(id)` —— 见 §5.3，返回 `{ plan, orphanTodoIds, synced, error? }`。
- `rowToPlan`：`generatedTodoIds` 字符串 → 数组（`JSON.parse`，异常→`[]`）；`isDeleted`/`isDefault` 布尔↔0/1。

id 生成：`import { randomUUID } from 'node:crypto'`（**静态 import**；勿用 `require('crypto')`——参见 todoRepo.quickCreate 既有写法，不在本子阶段改动，但**新代码必须静态**）。

### 5.5 IPC（`plans.ipc.ts` + `@shared/ipc` 加 `PLAN_*`）

沿用 ok/err 信封 + logger（**禁记 plan.content 明文**）。create/update 内部：先写 plan → 再 `syncPlanTodos` → 返回 `{ plan, generatedCount, orphanCount }`。

| 通道 | 入参 | 返回 data |
|---|---|---|
| `PLAN_GET` | `{ id }` | `Plan \| null` |
| `PLAN_LIST` | `{ from?, to?, type? }` | `Plan[]` |
| `PLAN_BY_DATE` | `{ date }` | `Plan \| null`（该日期最新一条） |
| `PLAN_CREATE` | `{ date, type?, content, templateId? }` | `{ plan, generatedCount, orphanCount }` |
| `PLAN_UPDATE` | `{ id, content, date?, type? }` | `{ plan, generatedCount, orphanCount }`（触发幂等再同步） |
| `PLAN_DELETE` | `{ id }` | `{ ok }`（软删；**不**软删其生成的 todos） |

- `PLAN_UPDATE` 幂等：同内容再存 → generatedCount=0（无新建）；改内容 → 增量建/复用。
- 失败信封：`err('INTERNAL'/'NOT_FOUND'/'PARSE_FAILED', msg)`；`PARSE_FAILED` 时 plan 仍已存（content 保原文），前端据此显示降级提示。

### 5.6 PlanView 激活（变动 `PlanView.vue`）

- 顶部：`<input type="date">`（默认今天）；变更 → 调 `PLAN_BY_DATE`：有则载入其 content/type；无则载入选定模板（沿用子阶段1模板选择器）。
- 主体：MarkdownEditor（不变）。
- 底部：**「保存」按钮启用**（替换子阶段1 disabled）。点击 → 有 `currentPlanId` 则 `PLAN_UPDATE`，否则 `PLAN_CREATE`。
- 反馈（**内联，禁模态**）：保存后显示状态行：`✅ 已保存，生成 N 条待办（流入今日待办卡）` 或 `⚠️ 已保存，但 N 条任务解析失败，已保留原文` 或 `ℹ️ N 条任务已移出计划，待办仍保留`。
- 保存按钮 loading 态防双击。

### 5.7 今日计划入口（变动 `TodayView.vue`）

- 今日待办卡标题区加一个轻量链接「📝 今日计划」→ `router.push('/plan')`（手帐风，token 色，无硬编码 hex）。

- **DB 锁定/损坏**：沿用全局安全模式（只读 + Toast）。
- **生成的 todo 与计划文档失配（残留）**：不自动删，仅提示，由用户在项目管理清理。
