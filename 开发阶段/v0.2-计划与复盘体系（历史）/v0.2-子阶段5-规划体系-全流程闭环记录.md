## 1. 单元目标
把「计划」+「复盘」两个顶层板块合并为统一「规划」，按日/周/月三级展开，每级同页完成「回顾本期（确定性或 AI）+ 规划下期」一线流转。日规划晚间回顾今日+规划明日；周统筹周末 AI 复盘本周+规划下周；月指导月末 AI 复盘本月+规划下月。任务级联：周/月 plan 的任务可点选下沉到下级，同步标记为已下沉。

## 2. 范围
**含**：
- IA 重构：侧栏「计划」+「复盘」→ 一个「规划」（可展开：日规划/周统筹/月指导），三子项对应 `/planning/{daily,weekly,monthly}` 路由
- 日规划（`/planning/daily`）：回顾今日（完成率环+已完成 todo 列表+遗留 todo）+ 规划明日（编辑日计划模板，保存后同步到 todos）
- 周统筹（`/planning/weekly`）：AI 结构化周复盘 Markdown（7 section）+ 规划下周（周计划模板，含月任务级联选择）
- 月指导（`/planning/monthly`）：AI 结构化月复盘 Markdown（4 section）+ 规划下月（月计划模板）
- AI 结构化复盘：周/月复盘按下级数据自动生成（可编辑+保存+重新生成），未配 LLM 时不报错、不发包、入口 disabled+非阻塞「去设置」
- 任务级联回写：周/月 plan 的 `- [ ]` 任务可点选「下沉」到下级（插入下级 plan），同步把上级任务标记为已下沉（`- [ ]` → `- [x]`）
- 确定性数据可视化：完成率环（期内已完成/期内全部）、月度每周条形图（任务总数+完成率）
- 自动提醒任务：周日启动→自动创建 todo「📌做周统筹·第N周」；月末启动→自动创建「📌做月指导·YYYY年M月」

**不含（推迟）**：
- AI 聊天/多轮问答（超范围）
- 计划模板的「标题」「时间分配」段（超范围，仅保留「任务」段）
- 周期任务（重复任务）
- 计划共享/协作

## 5. 核心设计

### 5.1 期键计算（`shared/period.ts`，新增纯函数）
- **周一始周日终**：`getWeekStart(date)` → 周一 ISO 串（跨年正确）
- **ISO 周数**：`isoWeekOf(date)` → `{year, week}`（周四法，ISO 8601）
- **月末**：`getMonthRange(date)` → `{start, end}`（start=1号 00:00，end=下月1号 00:00）
- **跨年/月末/闰年**：全 UTC 算术（`Date.UTC` + `getUTC*`），规避子阶段 3 LOW-1 时区问题
- **nextPeriodStart(level, dateStart)**：三级切换键算
  - `daily` → dateStart + 1 天
  - `weekly` → dateStart + 7 天
  - `monthly` → dateStart + 1 月（自动跨年）
- **periodLabel(level, dateStart)**：格式化「第N周」「YYYY年M月」
- **periodStartFor(level, date, reference?)**：归一化 date 到期起始（daily→当天/weekly→周一/monthly→1号）；非法 date 归当天

### 5.5 日规划（`/planning/daily`）
**回顾今日**：
- 完成率环（今日 todo 完成/全部）
- 已完成 todo 列表（`todos:completedToday`）
- 遗留 todo 列表（`todos:today` status=todo，可顺延到明日）

**规划明日**：
- 编辑器：日计划模板（`templateRepo.getByType('daily_plan_template')`），可编辑
- 保存：调 `plans:create/update` → 走子阶段 1 `syncPlanTodos`，生成 todos（generatedCount>0）
- CascadeRail：显示本周周任务（parentLevel=weekly），可选「下沉」到明日计划

### 5.6 周统筹（`/planning/weekly`）
**AI 复盘本周**：
- 完成率环（本周 todo 完成/全部）
- ReviewPanel：
  - 「生成」按钮 → 调 `reviews:summarizeWeekly(dateStart)`（主进程 LLM 调用）→ 返回 Markdown
  - 可编辑、可保存（`reviews:create(type='weekly_review',date=dateStart,content,generated=false)`）
  - 可重新生成（清空 → 再次 summarize）

**规划下周**：
- 编辑器：周计划模板（`weekly_plan_template`）
- 保存：**不生 todos**（runSync 门控，见 §5.9）
- CascadeRail：显示本月月任务（parentLevel=monthly），可选「下沉」到下周周计划

**AI 复盘 Markdown 结构（WEEKLY_REVIEW_SYSTEM_PROMPT）**：
1. 目标对照（本周计划完成情况）
2. 🔴 重大事件
3. 🟢 亮点
4. 🟡 不足·现象-原因-改进
5. ⚠️ 风险复查表（上周风险→本周状态）
6. ⚠️ 风险评估（当前风险）
7. ➡️ 下周建议

### 5.7 月指导（`/planning/monthly`）
**AI 复盘本月**：
- MonthlyCharts：
  - 整月完成率环
  - 每周双编码条形图（条长=任务总数相对最大周、填充=完成率、caption=W{isoWeek}）
- ReviewPanel：AI 月复盘 Markdown（MONTHLY_REVIEW_SYSTEM_PROMPT，4 section）
  - 整月宏观完成率图（MonthlyCharts）
  - 每周完成率分析
  - 风险评估
  - 经验教训
  - 下月建议

**规划下月**：
- 编辑器：月计划模板（`monthly_plan_template`）
- 保存：**不生 todos**
- 无 CascadeRail（月为顶级）

### 5.8 任务级联回写（CascadeRail）
- **数据源**：`plans:getByPeriod(parentLevel, curStart)` → 返回 plan 列表，每个 plan 用 `parseTasksWithState` 解析（`- [ ]`→consumed:false、`- [x]`→true）
- **显示**：仅未下沉的任务（consumed=false），Rail 卡片显示任务文本
- **选取**：
  - 用户点击任务 → 调 `pickTask(taskText, parentPlanId, parentLevel, curStart)`（usePlanning）
  - 插入下级 plan（`currentPlan.content += \`- [ ] ${taskText}\``）
  - 同步调 `plans:markTaskConsumed(parentPlanId)` → 上级 plan 该任务行 `- [ ]` → `- [x]`
- **幂等**：markTaskConsumed 已 `[x]` 或无匹配 → no-op
- **级联父周期换算**：日选周任务→parentStart=nextPeriodStart('weekly',curStart)（本周）；周选月任务→parentStart=nextPeriodStart('monthly',curStart)（本月）

### 5.9 runSync 门控（周/月 plan 保存不生 todo）
- **核心点**：周/月 plan 保存**不调 syncPlanTodos**（日计划仍调）
- `plans.ipc.ts` PLAN_CREATE/PLAN_UPDATE handler 内：
  - 调 `runSync(plan, generatedCount)`
  - `runSync`：`if(plan.type!=='daily_plan') return ok({plan,0,0})`（非 daily_plan 直接返回，不生成 todos）
- 理由：周/月 plan 任务是「备选池」，不应自动生成 todos；用户通过「下沉」手动选择

### 5.10 AI 调用（主进程 `services/llm.ts`）
**summarizeWeeklyReview(dateStart)**：
- `buildWeeklyContext(dateStart)`：聚合本周数据
  - `todos:completedInRange(weekStart,weekEnd)` → 截断 content（60 字）、最多 80 条
  - `plans:getByPeriod('daily_plan',weekStart)` → 本周所有日计划
  - `reviews:getByPeriod('weekly_review',prevWeekStart)` → 上周复盘（风险评估）
- 调用 `requestChat(system=WEEKLY_REVIEW_SYSTEM_PROMPT, user=context)`（主进程，settingsRepo 取 key）
- 返回 Markdown（`stripFence(content).slice(0,6000)`，剥围栏+限长）
- logger 仅记 latency/len（不泄露业务明文）

**summarizeMonthlyReview(monthStart)**：同理，buildMonthlyContext 聚合月度数据。

**错误降级**：
- 调用失败（401/403/429/5xx/网络/超时）→ 返回错误 code + message → ReviewPanel 显示红色状态条 + 可重试
- 单次不重试（用户手动重试）
- 模型输出异常（空/非 Markdown）→ stripFence+兜底

### 5.11 自动提醒（`services/reminders.ts`）
**启动时触发**（main/index.ts）：
- **周日**：`getWeekRange(today)[1]===today` → ensureTodo「📌做周统筹·第N周」（content 含 isoWeekOf，planDate=今天）
- **月末**：`getMonthRange(today)[1]===today` → ensureTodo「📌做月指导·YYYY年M月」（planDate=今天）
- ensureTodo：findByPlanDate(today).some(content===) → 幂等（已存在不重复）

**TodayView 交互**：

- 不触发 toggleTodo（@click.stop）

### 5.12 数据库查询扩展
**`planRepo.getByPeriod(type, dateStart)`**：
- `SELECT * FROM plans WHERE type=? AND date=? AND isDeleted=0 ORDER BY createdAt DESC LIMIT 1`
- 返回该期最新 plan（null → 模板）

**`reviewRepo.getByPeriod(type, dateStart)`**：同理。

**`todoRepo.findAllInRange(planDate)`**：
- `SELECT * FROM todos WHERE planDate>=? AND planDate<=? AND isDeleted=0`
- 用于期切换时加载本期全部 todo（完成率环）

**`todoRepo.findCompletedInRange(completedAt)`**：
- `SELECT * FROM todos WHERE status='done' AND isDeleted=0 AND completedAt>=? AND completedAt<?`
- 用于完成率环「已完成」计数（toExclusive=次日，避免跨期重复）

## 10. 禁止边界 & 错误降级（承袭项目计划 §7）
- **§9 日志**：summarizeWeekly/Monthly logger 仅记 latency/len；apiKey 不入 logger（redact 兜底+显式不传入）。
- **§9 token 红线**：用户主动触发（foreground），适用；但 context 聚合仅截断 todo content（≤60 字）、项目名/状态/计数，无敏感数据。
- **§9 软删除豁免**：markTaskConsumed 改 content 文本（物理更新 plan），不软删；提醒 todo 标准 create，用户可 softDelete。
- **LLM 失败降级**：红条+单次不重试+可重试；禁 alert/confirm。
- **无应用模态弹窗**：错误用模块内红色 err-bar；「去设置」router.push；透明提示内联 span。
- **XSS**：复盘 Markdown 经 MarkdownEditor(DOMPurify)；CascadeRail/periodLabel 全 `{{}}` 插值。
- **无硬编码 hex**：token 体系。
- **AI 仅用真实数据**：buildContext 仅取库内真实数据（todo 截断/项目计数/下级复盘摘要）；不外发 description/notes/inboxes。
- **未配 LLM**：入口 disabled+非阻塞「去设置」+ 不发包；代码路径：ReviewPanel disabled+去设置 span，usePlanning summarize 首行 `if(!llmReady) return`。
- **期键算错兜底**：periodStartFor 非法 date → todayStr()；跨年周/月末 vitest 覆盖。
- **markTaskConsumed 并发**：getByPeriod `ORDER BY createdAt DESC LIMIT 1`（最新）；无匹配 → ok(plan) 不崩。
- **无新表/无迁移**：schemaVersion 仍 3。

## 附录：关键设计亮点

1. **三级规划体系**：
   - 日规划（晚间）：回顾今日（完成率+已完成+遗留顺延）+ 规划明日
   - 周统筹（周末）：AI 结构化周复盘 + 规划下周
   - 月指导（月末）：AI 结构化月复盘 + 规划下月

2. **AI 结构化复盘生成**：
   - 周复盘：重大事件/亮点/不足·现象-原因-改进/上周风险复查/风险评估/下周建议
   - 月复盘：整月宏观完成率图 + 每周完成率图 + 风险评估 + 经验教训 + 下月建议

3. **任务级联回写**：
   - 周/月 plan 的 `- [ ]` 任务不生成 todos
   - 下级页面展示上级任务供「选取」→ 插入下级任务
   - 同步把上级任务标记为已下沉（`- [ ]` → `- [x]`）

4. **无迁移方案**：
   - 复用现有 plans/reviews/templates 三表
   - plans/reviews 的 `date` 作「期起始」（日=当天、周=周一、月=1号）
   - 存量数据自然归入「日规划」回顾
