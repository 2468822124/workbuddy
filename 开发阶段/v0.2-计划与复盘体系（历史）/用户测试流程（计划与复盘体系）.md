# WorkBuddy 用户测试流程 · 计划与复盘体系

> **写给**：江泽锋（最终用户 / 决策者）
> **目的**：在 dev 模式下逐项验证「计划与复盘体系」四个子阶段（基建 / 计划核心 / 复盘核心 / LLM 增强）。**你照做 → 出问题告诉我 → 我立修复计划。**
> **预计耗时**：20–35 分钟（造数据 + 测 LLM 需多花几分钟）
> **前置**：
> - dev 已启动（窗口已开，`WorkBuddy ready`）。**不要自己关掉再开新终端 `npm run dev`**——你系统的 `ELECTRON_RUN_AS_NODE=1` 会再次让窗口起不来，已由我清掉跑着。
> - 数据延续 v0.1.0：DB 在 `%APPDATA%\workbuddy\workbuddy.db`，计划/复盘/模板已就绪（迁移 3 已跑、3 个默认模板已 seed）。
> - 可选一个 OpenAI 兼容 LLM（DeepSeek / Kimi / 通义 / 中转站）的 API Key。**没 Key 也能测 P/Q/R/S/V**，只有 T/U（AI 引导/汇总）需它。
>
> 这是**增量功能测试**——v0.1.0 的基础流程（启动/安装/总览/项目/设置）已在开发阶段测过，本流程只测**计划与复盘新增能力**。

## 📋 总览（7 个阶段）

| 阶段 | 测什么 | 必须？ |
|---|---|:---:|
| P | 计划页：模板 + Markdown 编辑器（子阶段1 基建） | ✅ 必须 |
| Q | 计划保存 → 生成待办 + 幂等 + 流入总览（子阶段2 计划核心） | ✅ 必须 |
| R | 复盘保存 + 昨日复盘卡衔接（子阶段3 复盘核心） | ✅ 必须 |
| S | LLM 未配降级（按钮禁用 + 去设置，不发包） | ✅ 必须 |
| T | AI 引导（计划，逐占位符建议回填） | 有 Key 才测 |
| U | AI 汇总（复盘，自动生成草稿） | 有 Key 才测 |
| V | LLM 错 Key 降级（红色状态条 + 重试） | ✅ 必须 |

> 顺序建议：**P → Q → R → S → V**（不耗 Key，先打通核心）→ 配好 Key 再 **T → U**。
> 测 T/U 前最好先造点数据（待办/项目），AI 才有上下文可参考——每阶段会提示。

## 🛠 准备（一次性）

1. 确认 dev 窗口开着，停在「今日总览」。
2. **清场**（让测试结果干净）：
   - 进「今日总览」→ 把现有的测试待办删掉几条（可选，不删也行，只是计数会混）。
   - 计划页 / 复盘页如已有旧内容，可先不管。
3. （测 T/U 才需要）准备好你的 LLM 端点信息：Base URL / Model / API Key。

> 全程**不用怕搞坏**——所有数据都在 `%APPDATA%\workbuddy\`，彻底退出 WorkBuddy 后删掉这个文件夹即重置。

## P. 计划页：模板 + Markdown 编辑器（基建验收）

### P1. 进入计划页
1. 左侧栏点「**计划**」。

**✅ 应看到**：
- 顶部「计划」标题 + 日期选择器（默认**今天**）
- 一行工具栏：模板下拉 + 「✨ AI 引导」按钮 + 「保存」按钮
- 下方 Markdown 编辑器（左侧文本框 + 右侧预览，或可切换）
- 模板下拉默认选中「日计划」

**❌ 失败现象**：页面空白 / 报错 / 没有编辑器 / 模板下拉空。

### P2. 切换模板
1. 模板下拉选「**日计划**」→ 编辑器应填入日计划模板（含 `{{date}}` `{{focus}}` 等占位符 + `- [ ]` 任务框）。
2. 再切「**周计划**」（若有）→ 内容应变。

**✅ 应看到**：切换模板后编辑器内容跟着变。

**❌ 失败**：切了没反应 / 内容不变。

### P3. Markdown 编辑器工具栏
1. 编辑器顶部工具栏试几个按钮：**粗体**（Ctrl+B 也行）、**标题**、**任务**（插 `- [ ]`）。
2. 点预览切换图标（眼睛）→ 预览区应实时渲染你写的 Markdown（标题加粗、任务框可勾——但预览里勾选不可交互，正常）。

**✅ 应看到**：工具栏插入语法正确；预览实时渲染。

**❌ 失败**：工具栏点了没插入 / 预览不渲染 / 渲染崩。

## Q. 计划核心：保存生成待办 + 幂等（计划核心验收）

> 这是子阶段2 的关键：计划里写的 `- [ ] 任务` 保存时自动变成待办，流入今日总览。**幂等**是重点——重复保存不重复生成。

### Q1. 写计划 + 保存
1. 确认计划页日期 = **今天**。
2. 在编辑器里写几条未勾任务（点工具栏「任务」按钮快速插，或手敲）：
   ```
   - [ ] 写测试报告
   - [ ] 调研竞品
   - [ ] 开会
   ```
3. 点「**保存**」。

**✅ 应看到**：保存按钮变「保存中…」→ 出反馈条「✅ 已保存，生成 3 条待办（流入今日待办卡）」。

**❌ 失败**：保存失败 / 不生成待办 / 报错。

### Q2. 待办流入总览
1. 左侧栏回「**今日总览**」。
2. 看「今日待办」卡。

**✅ 应看到**：刚才 3 条任务出现在今日待办卡（「写测试报告」「调研竞品」「开会」），计数 +3。

**❌ 失败**：总览不显示这些任务（数据流断了，**必报**）。

### Q3. 幂等（重复保存不重建）—— 重点
1. 回「计划」页（不改任何内容）。
2. 再点一次「**保存**」。

**✅ 应看到**：反馈变「✅ 已保存，无新增任务」（**不是**又生成 3 条）。

**❌ 失败**：又生成 3 条 / 总览待办翻倍（幂等坏了，**必报**）。

### Q4. 完成态保留
1. 回「今日总览」→ 勾掉「**写测试报告**」（变已完成、划除）。
2. 回「计划」页 → 点「保存」（计划内容没变）。
3. 回「今日总览」。

**✅ 应看到**：「写测试报告」**仍是已完成态**（没被重置为未完成），「调研竞品」「开会」仍未完成。

**❌ 失败**：已完成的那条被重置为未完成（完成态没保留，**必报**）。

### Q5. 改日期（计划独立于日期）
1. 计划页日期选**明天** → 编辑器应变空（明天还没计划）。
2. 写点内容 → 保存。
3. 回总览（日期还是今天）→ 今天待办**不应**出现明天的任务。

**✅ 应看到**：不同日期的计划相互独立；明天的任务不混进今天总览。

**❌ 失败**：日期切换错乱 / 跨日任务混流。

## R. 复盘核心：保存 + 昨日复盘卡衔接（复盘核心验收）

### R1. 进入复盘页
1. 左侧栏点「**复盘**」。

**✅ 应看到**：
- 顶部「复盘」标题 + 日期选择器（默认**昨天**——因为复盘通常复盘前一天）
- 模板下拉（日复盘/周复盘）+ 「✨ AI 汇总」按钮 + 「保存」按钮
- 编辑器默认填入日复盘模板

**❌ 失败**：默认日期不是昨天 / 模板空 / 报错。

### R2. 写复盘 + 保存
1. 确认日期 = **昨天**（如不是，手动选昨天）。
2. 编辑器里在模板基础上写点内容（比如「今日完成：xxx」「反思：xxx」）。
3. 点「**保存**」。

**✅ 应看到**：反馈条「✅ 已保存」。

**❌ 失败**：保存失败。

### R3. 昨日复盘卡衔接 —— 重点
1. 左侧栏回「**今日总览**」。
2. 找「**昨日复盘**」卡（v0.1.0 时它是空态「敬请期待」，现在应激活）。

**✅ 应看到**：昨日复盘卡**不再是空态**，而是显示你刚写的昨日复盘的**摘要文字**（前几行纯文本），右下有「📝 查看/编辑」入口。

**❌ 失败**：仍是空态「敬请期待」/ 不显示摘要 / 报错（衔接断了，**必报**）。

### R4. 跳转预填
1. 点昨日复盘卡的「**📝 查看/编辑**」。

**✅ 应看到**：跳到复盘页，**日期自动预填为昨天**，编辑器加载你昨天写的内容。

**❌ 失败**：跳了但日期没预填 / 内容没加载。

### R5. 今日复盘
1. 复盘页日期改选**今天**。
2. 应加载空模板（今天还没写复盘）。
3. 写两句 → 保存 → 「✅ 已保存」。

**✅ 应看到**：今天与昨天的复盘独立存储，互不覆盖。

**❌ 失败**：保存今天的覆盖了昨天的 / 日期错乱。

## S. LLM 未配降级（必须通过，不耗 Key）

> 核心安全验收：没配 AI 时，AI 入口必须**禁用 + 不发任何网络请求**。

### S1. 确认 LLM 未配
1. 进「**设置**」→ AI 配置。
2. 若已填 Key，**临时清空 API Key**（或 Base URL）→ 保存。（测完 T/U 再填回）

### S2. 计划页降级态
1. 回「**计划**」页。

**✅ 应看到**：
- 「✨ AI 引导」按钮**灰色禁用**（点不动）
- 按钮旁显示「**去设置**」链接（不是透明提示，是去设置入口）
- 点「去设置」→ 跳到设置页

**❌ 失败**：按钮能点 / 点了发请求 / 「去设置」不跳（**必报**——这是禁止边界）。

### S3. 复盘页降级态
1. 回「**复盘**」页 → 看「✨ AI 汇总」按钮。

**✅ 应看到**：同 S2——按钮灰禁用 + 「去设置」链接，点不动、不发请求。

**❌ 失败**：同 S2。

> 测完 S，**配好你的 LLM 端点**（Base URL / Model / API Key）保存，继续 T / U。

## T. AI 引导（计划页，需 Key）

> AI 看你的待办和项目，给计划里每个占位符（`{{focus}}` 等）一条贴合的建议，你逐条采纳回填。

### T0. 造上下文（让 AI 有东西可参考）
1. 进「**项目**」→ 建一个进行中项目（如「WorkBuddy 推广」，状态「进行中」）。
2. 进项目详情 → 加 2–3 个 todo，计划日期选**今天**或**昨天**（造点「今日待办/逾期」）。
3. 回总览确认这些待办出现。

### T1. 引导按钮激活
1. 回「**计划**」页（日期=今天）。

**✅ 应看到**：「✨ AI 引导」按钮**不再灰色**（变可点），按钮旁透明提示「基于你的待办与项目，调用你配置的 AI」。

**❌ 失败**：按钮仍灰（配置没生效，可能需刷新页面或重开 app 让它重新探测）。

### T2. 触发引导
1. 点「**✨ AI 引导**」。

**✅ 应看到**：按钮变「思考中…」→ 下方出内联面板「**AI 思考中…**」+ 旋转图标。等 5–20 秒。

**❌ 失败**：一直转超 30 秒 / 直接报错。

### T3. 引导结果
1. 面板应出现**逐条卡片**，每条：
   - 「📌 占位符名」（如 focus / progress）
   - 一句引导提问
   - 一条贴合你待办的建议（可能点名你的待办/项目）
   - 「**插入**」+「**跳过**」按钮

**✅ 应看到**：多条引导卡片；建议里提到你造的待办/项目名（没瞎编）。

**❌ 失败**：空白 / 瞎编不存在的任务 / 报错。

### T4. 插入回填
1. 点某条的「**插入**」。

**✅ 应看到**：编辑器里对应的 `{{占位符}}` 被**替换为该建议内容**（花括号占位符消失，变成建议文字）。

**❌ 失败**：插入后占位符还在 / 插到错误位置 / 内容没变。

### T5. 跳过
1. 另一条点「**跳过**」。

**✅ 应看到**：该卡片从面板移除，编辑器内容**不变**。

**❌ 失败**：跳过却改了内容。

### T6. 关闭面板
1. 面板右上「**×**」→ 面板关闭。

**✅ 应看到**：面板消失，编辑器保留已插入的内容。

## U. AI 汇总（复盘页，需 Key）

> AI 看你某天完成的任务和项目进展，自动生成一份日复盘草稿。

### U0. 造完成数据
1. 进总览或项目页 → 把几条 todo **勾选为已完成**（completedAt = 今天）。
2. （或选一个已经有完成任务的日期来测）

### U1. 汇总按钮激活
1. 回「**复盘**」页，日期选**今天**（有完成任务的那天）。
2. 看「✨ AI 汇总」按钮应可点 + 透明提示。

### U2. 触发汇总
1. 点「**✨ AI 汇总**」→ 「思考中…」→ 等几秒。

**✅ 应看到**：出草稿面板——上方是**草稿预览**（Markdown 渲染，含完成概述/进展/反思/明日点），下方一行：「⚠️ 替换将覆盖当前内容」+「**替换内容**」+「**追加到末尾**」+「**取消**」。

**❌ 失败**：一直转 / 报错 / 草稿用了 `- [ ]` 任务框（规则要求用普通列表 `-`，**必报**）。

### U3. 替换内容
1. 编辑器先随便写几个字（测覆盖警告是否生效）。
2. 点「**替换内容**」。

**✅ 应看到**：编辑器原内容**被草稿整个替换**（你刚写的字没了，变成草稿）。

**❌ 失败**：没替换 / 替换后混入旧内容。

### U4. 追加到末尾
1. 再点一次「AI 汇总」重新生成。
2. 点「**追加到末尾**」。

**✅ 应看到**：草稿**接到现有内容后面**（原内容保留 + 草稿在末尾）。

**❌ 失败**：覆盖了原内容 / 没追加。

### U5. 取消
1. 再生成一次 → 点「**取消**」。

**✅ 应看到**：面板关闭，编辑器内容**完全不变**。

### U6. 无数据占位（边界）
1. 复盘页日期选一个**没有任何完成任务**的日期（比如很早的某天）。
2. 点「AI 汇总」。

**✅ 应看到**：**很快**（没等 AI 思考）直接出占位草稿「# 日复盘草稿 · {日期}…（当日暂无完成任务记录，可手动补充今日收获与反思。）」，**不报错、不转圈**。

**❌ 失败**：还是去调 AI（转圈）/ 报错（**必报**——无数据应短路不调 LLM）。

## V. LLM 错 Key 降级（必须通过）

### V1. 改错 Key
1. 进「设置」→ API Key 改成错的（如 `sk-wrong123`）→ 保存。

### V2. 计划页错 Key
1. 回「计划」页 → 点「✨ AI 引导」。

**✅ 应看到**：面板出现**红色状态条**「API Key 无效或已过期，请前往设置检查」+「**重试**」按钮（**不是系统弹窗，应用不崩**）。

**❌ 失败**：崩 / 卡死 / 弹系统报错框 / 自动疯狂重试。

### V3. 复盘页错 Key
1. 回「复盘」页 → 点「✨ AI 汇总」→ 同样红色状态条 + 重试。

### V4. 单次不重试
- 观察：红条出现后**不应自动重发请求**，只有你手动点「重试」才会再发一次。

**✅ 应看到**：失败一次就停，等你手动重试。

**❌ 失败**：失败后自动循环重发（拖死 API，**必报**）。

> 测完 V，记得把 Key 改回正确的（如还要继续用）。
