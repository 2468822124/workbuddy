## 0. 元信息
- **阶段**：阶段 5 — 对话式热点搜索（LLM）
- **快/稳**：快

- **本阶段无后台 LLM 调用**：所有调用均为用户前台主动触发，§9 后台 1000-token 红线 N/A（仍设输出/上下文成本护栏，见 §5、§10）。

## 1. 阶段目标
在今日热点卡内，用户用自然语言提问（如「今天 AI 圈有什么新鲜事？」），Agent 基于本地已抓取的今日热点（`news_items` 缓存）实时调用用户自配的 OpenAI 兼容 LLM，返回一段自然语言回答 + 若干「结果卡」（引用的热点），点击结果卡打开原文。未配 LLM 时搜索条禁用并给出「去设置」入口，不发起任何网络请求。

## 2. 范围
**含**：
- 激活 `TodayView.vue` 中 `.chat-bar.disabled` 占位为可用的对话搜索条（输入 + 提交）。
- 未配 LLM（`llmBaseUrl`/`llmModel`/`llmApiKey` 任一为空）→ 禁用态 + 非阻塞「去设置」入口（跳 `/settings`）。
- 已配 → 主进程读取库内配置（`llmApiKey` 密文读出）、取 `news_items` top N 作上下文、调 OpenAI 兼容 `chat/completions`，强制结构化 JSON 输出（`answer` + `refs`）。
- 结果渲染：自然语言回答 + 引用结果卡（link 取自本地 `news_items`，**非模型生成**）；点击 → 打开原文（复用 `TodayView` 现有 `openLink`/`window.open`）。
- 鲁棒降级：模型未按 JSON 回答 → 保留原文为 answer、refs 置空，不崩溃。
- 错误降级：401/403、429、5xx、网络错、超时 → 单次不重试 + 卡内红色状态条（非模态）。

**不含（推迟）**：
- 多轮对话上下文 / 历史持久化（本阶段为**单轮一问一答**，结果仅存内存，刷新即清；不建 `chats` 表）。
- 模型自动拉取 / 联网搜索（仅基于本地 `news_items` 缓存）。
- 结果收藏 / 转待办 / 流式（streaming）输出。
- 将搜索条改造为 `shell.openExternal` 真系统浏览器（沿用阶段 2 已实现的 `window.open`，保持一致；列为后续改进）。

## 3. 技术栈与本阶段新增依赖
无新依赖。HTTP 复用 Node 22 全局 `fetch` + `AbortController`（同阶段 4）。新增**共享常量**（放 `shared/constants.ts`，均 UPPER_SNAKE_CASE）：

| 常量 | 值 | 用途 |
|---|---|---|
| `LLM_NEWS_CONTEXT_LIMIT` | `15` | 单次搜索注入 `news_items` 的最大条数（成本护栏） |
| `LLM_CHAT_MAX_TOKENS` | `600` | `chat/completions` 输出上限（前台触发，红线 N/A，但限输出） |
| `LLM_CHAT_TIMEOUT_MS` | `30_000` | 单次搜索 AbortController 超时（聊天比 ping 重，放宽到 30s） |
| `LLM_QUERY_MAX_CHARS` | `200` | 用户输入字符上限（前端 + IPC 复校，防滥用） |
| `LLM_REFS_MAX` | `5` | 返回结果卡数量上限（按模型给出顺序截断 + 去重） |

## 5. 核心设计

### 5.1 服务层：`searchNews()`（`services/llm.ts` 新增，复用阶段 4 范式）
```ts
// 仅供主进程调用；读库内配置，不接收 apiKey 入参
export class ChatError extends Error {
  constructor(public code: string, message: string) { super(message); this.name = 'ChatError' }
}
export async function searchNews(query: string): Promise<ChatResult> {
  // 1. 读配置（settingsRepo.get 自动解密 llmApiKey）
  const base = settingsRepo.get('llmBaseUrl')?.value?.trim()
  const model = settingsRepo.get('llmModel')?.value?.trim()
  const apiKey = settingsRepo.get('llmApiKey')?.value   // 已解密
  if (!base || !model || !apiKey) {
    throw new ChatError('LLM_NOT_CONFIGURED', '未配置 AI，请先在设置中填写 Base URL、Model 与 API Key')
  }

  // 2. 取上下文（只读 news_items；不触碰任何私有业务表）
  const context = newsRepo.list(LLM_NEWS_CONTEXT_LIMIT)
  if (context.length === 0) {
    return { answer: '暂无热点数据，请先在今日热点卡点击「刷新热点」。', refs: [], latencyMs: 0 }
  }

  // 3. 组装 messages（system 强制 JSON；user 注入编号热点 + 问题）
  const messages = buildMessages(context, query)   // 见 5.2

  // 4. fetch（baseUrl 去尾斜杠 + '/chat/completions'；AbortController 超时）
  const started = Date.now()
  const controller = new AbortController()
  const timer = setTimeout(() => controller.abort(), LLM_CHAT_TIMEOUT_MS)
  let res: Response
  try {
    res = await fetch(base.replace(/\/+$/, '') + '/chat/completions', {
      method: 'POST',
      headers: { 'Authorization': `Bearer ${apiKey}`, 'Content-Type': 'application/json' },
      body: JSON.stringify({ model, messages, temperature: 0.3, max_tokens: LLM_CHAT_MAX_TOKENS, stream: false }),
      signal: controller.signal,
    })
  } catch (e: unknown) {
    clearTimeout(timer)
    if ((e as Error).name === 'AbortError') throw new ChatError('LLM_TIMEOUT', 'AI 响应超时（>30s），请稍后重试')
    throw new ChatError('LLM_NETWORK', '网络连接失败，请检查网络或 Base URL')
  }
  clearTimeout(timer)
  const latencyMs = Date.now() - started

  // 5. 状态码 → ChatError（单次不重试）
  if (res.status === 401 || res.status === 403) throw new ChatError('LLM_AUTH', 'API Key 无效或已过期，请前往设置检查')
  if (res.status === 429)                 throw new ChatError('LLM_RATE_LIMIT', '请求过于频繁，请稍后再试')
  if (res.status >= 500)                  throw new ChatError('LLM_UNAVAILABLE', `AI 服务暂时不可用（${res.status}），请稍后重试`)
  if (!res.ok)                            throw new ChatError('LLM_ERROR', `AI 返回异常（${res.status}）`)

  // 6. 解析 content → 鲁棒 JSON
  const raw = await extractContent(res)            // data.choices[0].message.content（容错缺失）
  const parsed = parseChatJson(raw)                // 见 5.3；失败返 null
  const answer = parsed ? parsed.answer : raw.slice(0, 500)   // 降级：原文为 answer
  const refs = parsed ? mapRefs(parsed.refs, context) : []    // 见 5.4

  // 7. 日志：仅记 latency / refs 数 / 状态，**不记 answer 明文、不记 apiKey**
  logger.info(`chat search OK, ${latencyMs}ms, refs=${refs.length}`)
  return { answer, refs, latencyMs }
}
```
> **apiKey 永不入日志**：阶段 4 `logger.redact` 兜底（键名匹配 `apiKey` 自动 `***REDACTED***`），且本函数 `logger.info` 显式不传入 answer/apiKey。错误分支仅记 `ChatError.code`。

### 5.2 消息组装（`buildMessages`，system prompt 逐字实现）
```ts
const SYSTEM_PROMPT = `你是 WorkBuddy 的热点助手。请仅依据用户提供的「今日热点」列表回答问题，不得编造列表之外的信息或链接。
规则：
1. 若列表中没有相关信息，在 answer 中如实说明，refs 返回空数组 []。
2. answer 用中文，简洁（不超过 150 字），口语、可读。
3. 引用真实存在的热点：refs 中每个 index 必须是列表里的编号（从 1 开始），reason 用一句话说明相关性（不超过 30 字）。
4. 不要输出任何链接；链接由系统根据 index 自动补全。
5. 必须只输出一个 JSON 对象，不要包含任何解释或 markdown 代码块标记：
{"answer":"...","refs":[{"index":1,"reason":"..."}]}`

function buildMessages(context: NewsItem[], query: string) {
  const list = context.map((n, i) =>
    `[${i + 1}] 《${n.title}》 来源：${n.source}${n.publishedAt ? ` · ${n.publishedAt.slice(0, 10)}` : ''}\n摘要：${n.summary ?? '无'}`
  ).join('\n\n')
  return [
    { role: 'system', content: SYSTEM_PROMPT },
    { role: 'user', content: `今日热点（共 ${context.length} 条）：\n${list}\n\n用户问题：${query}\n\n请按系统提示的 JSON 格式回答。` },
  ]
}
```

### 5.3 鲁棒 JSON 解析（`parseChatJson`）
```ts
// 容错：剥离 ```json 代码块围栏；取首个 '{' 到末个 '}'；解析失败 → null（调用方降级为原文 answer）
function parseChatJson(raw: string): { answer: string; refs?: { index: number; reason?: string }[] } | null {
  let s = raw.trim()
  const fence = s.match(/```(?:json)?\s*([\s\S]*?)```/i)
  if (fence) s = fence[1].trim()
  const first = s.indexOf('{'); const last = s.lastIndexOf('}')
  if (first === -1 || last <= first) return null
  try {
    const obj = JSON.parse(s.slice(first, last + 1))
    return typeof obj.answer === 'string' ? obj : null
  } catch { return null }
}
```

### 5.4 引用映射（`mapRefs`，绝不信任模型链接）
```ts
// index → 本地 context[index-1]；越界/重复丢弃；reason 截断 80 字；上限 LLM_REFS_MAX
function mapRefs(refs: { index: number; reason?: string }[] | undefined, context: NewsItem[]): ChatRef[] {
  const seen = new Set<string>(); const out: ChatRef[] = []
  for (const r of refs ?? []) {
    const i = Number(r?.index)
    if (!Number.isInteger(i) || i < 1 || i > context.length) continue
    const item = context[i - 1]
    if (seen.has(item.id)) continue
    seen.add(item.id)
    out.push({ item, reason: String(r.reason ?? '').slice(0, 80) })
    if (out.length >= LLM_REFS_MAX) break
  }
  return out
}
```

### 5.5 IPC handler（`llm.ipc.ts` 增，同文件 `registerLlmIpc` 内）
```ts
ipcMain.handle(IPC.LLM_SEARCH, async (_e, query: string) => {
  try {
    if (!query || !query.trim()) return err('INVALID', '请输入问题')
    if (query.length > LLM_QUERY_MAX_CHARS) return err('INVALID', `问题过长（超过 ${LLM_QUERY_MAX_CHARS} 字）`)
    const result = await searchNews(query.trim())
    return ok(result)
  } catch (e: unknown) {
    if (e instanceof ChatError) { logger.warn(`chat search failed: ${e.code}`); return err(e.code, e.message) }
    logger.error('llm:search error', e)
    return err('INTERNAL', `内部错误：${(e as Error).message}`)
  }
})
```

### 5.6 渲染层组合式（`composables/useHotspotChat.ts`，自包含）
```ts
export function useHotspotChat() {
  const api = useApi()
  const llmReady = ref(false)
  const query = ref('')
  const result = ref<ChatResult | null>(null)
  const loading = ref(false)
  const error = ref<{ code: string; message: string } | null>(null)

  async function checkReady() {           // 探测三项配置是否齐备（非空）
    const [b, m, k] = await Promise.all([
      api.settings.get('llmBaseUrl'), api.settings.get('llmModel'), api.settings.get('llmApiKey'),
    ])
    llmReady.value = !!(b.ok && b.data.value.trim() && m.ok && m.data.value.trim() && k.ok && k.data.value.trim())
  }
  async function search() {
    const q = query.value.trim()
    if (!q || loading.value) return
    if (q.length > LLM_QUERY_MAX_CHARS) { error.value = { code: 'INVALID', message: `问题过长（超过 ${LLM_QUERY_MAX_CHARS} 字）` }; return }
    if (!llmReady.value) { error.value = { code: 'LLM_NOT_CONFIGURED', message: '未配置 AI，请先前往设置' }; return }
    loading.value = true; error.value = null; result.value = null
    const r = await api.llm.search(q)
    loading.value = false
    if (r.ok) result.value = r.data; else error.value = r.error
  }
  function clear() { result.value = null; error.value = null; query.value = '' }
  function openLink(url: string) { window.open(url, '_blank') }   // 与 TodayView 一致

  onMounted(checkReady)
  return { llmReady, query, result, loading, error, search, clear, openLink }
}
```
