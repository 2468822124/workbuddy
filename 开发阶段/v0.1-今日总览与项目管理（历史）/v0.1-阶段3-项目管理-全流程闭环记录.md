## 1. 阶段目标
用户可新建/编辑/归档项目，在看板与列表间切换，进入项目详情管理其任务（创建/编辑/勾选/删除）。项目内 `planDate=今天` 的任务自动出现在今日总览。

## 2. 范围
**含**：
- 项目 CRUD（新建/编辑/软删除）
- 看板视图（4 列：进行中 active / 已暂停 paused / 已完成 done / 已放弃 dropped）+ 列表视图，可切换
- 看板拖拽（HTML5 DnD，无新依赖）跨列改 status；另提供编辑表单改 status（无障碍兜底）
- 项目详情页 `/projects/:id`：编辑名称/描述/status；任务列表（按 projectId）；新增任务（content + planDate）；编辑任务（content/planDate）；勾选完成；软删除任务
- 项目/任务列表带计数（任务总数/未完成数）
- 数据闭环：项目任务 `planDate=today` → 今日总览「今日待办」出现

**不含（推迟）**：
- 项目详情「关联笔记」→ 显示「敬请期待」空状态（知识库阶段）
- 子任务/优先级/截止时间提醒（超范围）
- 项目归档/导出

## 5. 核心设计

### 5.1 看板（KanbanBoard / KanbanColumn / ProjectCard）
- 4 列对应 `ProjectStatus`，列头：名称 + 该状态项目数。
- `ProjectCard`：`draggable="true"`；`@dragstart` → `e.dataTransfer.setData('text/plain', project.id)`。
- `KanbanColumn`（drop zone）：`@dragover.prevent`（允许 drop）；`@drop` → 读 id → 调 `projects:update(id, {status: 本列 status})` → 本地移动卡片（乐观更新，失败回滚）。
- 卡片显示：名称、描述首行、`openTasks/totalTasks` 计数 chip、状态色点。
- 卡片点击（非拖拽）→ `router.push('/projects/'+id)`。
- **无障碍兜底**：`ProjectForm` 编辑模式含 status 下拉，键盘/不拖拽也能改状态。

### 5.2 列表视图（ProjectListView）
- 表格式列表：名称 / 状态徽标 / 任务数(未完成/总) / 创建时间 / 操作（编辑、删除）。
- 顶部与看板共用「视图切换」段控（看板 | 列表）+「新建项目」按钮。
- 视图偏好持久化到 `localStorage`（键 `wb_proj_view`），非业务数据，可不入库。

### 5.3 项目表单（ProjectForm，内联面板）
- 字段：name（必填，≤80 字符）、description（≤500 字符，选填）、status（下拉，编辑时可见）。
- 提交 → create 或 update；**内联展示**（页面顶部滑入面板或行内展开），**禁模态弹窗**。
- 输入渲染：`{{ }}` 文本插值，**禁 v-html**（防 XSS）；长度超限前端拦截并就近提示。

### 5.4 项目详情（ProjectDetailView，路由 `/projects/:id`）
- 顶部：返回链接 + 项目名（点击进入编辑）+ status 徽标 + 「编辑」「删除」操作。
- 描述区：只读展示，编辑模式下为 textarea。
- 任务列表：`todos:byProject(id)` → `TaskRow`（勾选框 + content 可编辑 + planDate 日期选择 + 软删除）。
- 新增任务行：content 输入 + planDate(`<input type="date">`) + 回车/按钮 → `todos:create({content, planDate, projectId:id})`。
- **关联笔记**：`<EmptyState icon="Library" title="关联笔记即将上线" />`。
- **项目不存在**（id 找不到 / 已软删）：显示 EmptyState「项目不存在或已删除」+ 返回链接，**不崩溃**。

### 5.5 删除确认（无模态）
- 删除项目/任务：点「删除」→ 该行/卡片就地变为「确认删除？[确认] [取消]」内联条；点确认才 softDelete；3 秒不操作自动取消。**不得用 alert/confirm/dialog 模态**。

### 5.6 数据闭环（跨阶段）
- 项目任务 `planDate = today` → 阶段 2 `todos:today` 天然命中（查询按 planDate 过滤，与 projectId 无关）→ 今日总览「今日待办」自动出现。无需改阶段 2 代码。
- 删除项目**不级联删任务**（任务独立；§9 禁自动物理删）；任务 `projectId` 外键 `ON DELETE SET NULL`，但软删项目不会触发（仅标记 isDeleted）。→ 项目软删后，其任务仍在 TodayView 按 planDate 显示（独立留存，符合预期）。

## 6. 数据模型变更
**无新表/无新迁移。** 复用阶段 1 的 `projects` / `todos`。新增共享类型：
```ts
export interface ProjectWithCounts extends Project {
  totalTasks: number
  openTasks: number   // status='todo' 且未删
}
export interface CreateTodoInput {
  content: string
  planDate: string | null
  projectId: string | null
}
```
`projectRepo` 增 `listWithCounts()`（LEFT JOIN 聚合，见 §7）。

## 7. IPC 契约（`shared/ipc.ts` 新增）
| 通道 | 入参 | 返回 `Result<T>` | 说明 |
|---|---|---|---|
| `projects:list` | — | `ProjectWithCounts[]` | 含任务计数，isDeleted=0 |
| `projects:get` | id | `ProjectWithCounts \| null` | 单个+计数 |
| `projects:create` | `{name, description?, status?}` | `Project` | 默认 status=active |
| `projects:update` | `{id, name?, description?, status?}` | `Project` | 部分更新 |
| `projects:delete` | id | `boolean` | 软删除 |
| `todos:byProject` | projectId | `Todo[]` | isDeleted=0，按 createdAt desc |
| `todos:create` | `CreateTodoInput` | `Todo` | 完整创建（含 projectId/planDate） |
| `todos:update` | `{id, content?, planDate?}` | `Todo` | 编辑 |
| `todos:delete` | id | `boolean` | 软删除 |

（阶段 2 通道 `todos:today/overdue/toggle/rescheduleToday/quickCreate` 保留不变。）

`projectRepo.listWithCounts()` SQL：
```sql
SELECT p.*,
  COUNT(t.id) AS totalTasks,
  SUM(CASE WHEN t.status='todo' AND t.isDeleted=0 THEN 1 ELSE 0 END) AS openTasks
FROM projects p
LEFT JOIN todos t ON t.projectId = p.id AND t.isDeleted = 0
WHERE p.isDeleted = 0
GROUP BY p.id
ORDER BY p.createdAt DESC
```

## 10. 禁止边界 & 错误降级（承袭并具化）
- **§9 软删除**：项目/任务删除一律 `isDeleted=1`；查询默认过滤；**禁物理删除**；**不级联删任务**。
- **无模态弹窗（§9）**：删除确认用内联条；新建/编辑用内联面板；**禁 alert/confirm/dialog/Electron 模态**。
- **XSS**：名称/描述/任务内容渲染用 `{{}}`，**禁 v-html**；输入长度上限（name 80 / description 500 / todo content 200）。
- **无硬编码 hex**：状态色用现有 token（active→`--accent`、paused→`--warn`、done→`--ok`、dropped→`--text-muted`）；不引新色值。
- **DnD 降级**：拖拽失败/不支持 → 编辑表单 status 下拉仍可改（无障碍兜底）。
- **乐观更新失败回滚**：拖拽/删除失败 → 复位 + 非阻塞 Toast/状态条提示。
