## 逐项详情

### 1. D5 — 任务行无删除/编辑键

- **根因**（GLM 已诊）：`AppIcon.vue` 未注册 `Pencil`/`Trash2` → `<component :is="undefined">` 渲染为空 → 纯图标按钮不可见。
- **改动**：`AppIcon.vue` import + icons map 各补 `Pencil, Trash2, Download, Upload`（4 个；`Download`/`Upload` 为 grep 全渲染层 `<AppIcon name="X">` 附带发现的同类漏注，SettingsView.vue:90-94 导入导出按钮使用）。
- **grep 核验**：全渲染层静态 `<AppIcon name="...">` 32 处 + 动态绑定（AppSidebar `item.icon`、MarkdownEditor `b.icon`、EmptyState `icon as any`、`Eye/EyeOff` 三态）逐一核对 → 现有 name 全集 ⊆ 已注册集，**无其他漏注**。
- **既有链路未动**（GLM 已验，本次仅注册图标）：TaskRow.vue 编辑/删除按钮 + 删除二次确认 → `useProjectDetail.deleteTodo` → `api.todos.delete` → `todoRepo` 软删（isDeleted=1）。

### 2. E1 — 测试连接误报成功

- **根因**：`testConnection` 仅查 `res.ok`，任何 2xx（含 HTML soft-404/error 形态 body）都判成功。
- **改动**：成功分支先 `parseTestBody(res)`——读 body 文本，首字符非 `{`/`[`（HTML/纯文本）→ false；JSON.parse 失败 → false；`choices[0].message.content` 非字符串 → false。false → `{ok:false, message:'该地址未返回有效的 AI 响应，请确认 Base URL 指向 OpenAI 兼容的 /chat/completions 端点（如 https://api.deepseek.com）'}`。
- **保留**：401/403/429/5xx 既有 message 映射、10s 超时、`max_tokens:1`、apiKey 不入日志（logger 不传 cfg）。

### 3. U6 — 无数据仍调 AI

- **根因**：`done.length===0 && projects.length===0` 中 `findActive()` 无日期过滤恒非空 → 短路永不触发。
- **改动**：条件改 `if (done.length === 0)`，占位草稿文案不变。`projects` 仍取（进入 LLM 路径时作上下文），`findActive` 不改（爆炸半径控制）。

### 4. P2 — 补周计划模板

- **改动**：`DEFAULT_TEMPLATES` 增第 4 条 `{id:'tpl-default-weekly-plan', name:'周计划', type:'weekly_plan', content: 按反馈 §2.4 逐字}`，emoji 转义对齐既有（🗓️=`\u{1F5D3}️`、🎯=`\u{1F3AF}`、✅ 直留、📅=`\u{1F4C5}` 同日计划、📝=`\u{1F4DD}`）。
- **幂等**：`seedDefaults()` 按固定 id 检查（`src/main/index.ts:58` 启动即跑）→ 存量库重启自动补，无迁移。
- **已确认**：`TemplateType` union 已含 `weekly_plan`；`PlanView.vue:34` 已请求 `weekly_plan`；默认选中仍是日计划（L146 `isDefault && type==='daily_plan'`）。`{{week}}`/`{{focus}}` 占位符与周复盘同日计划同机制（保存后由用户/AI 引导填充），`syncPlanTodos` 不改（周计划任务落所选日期待办为已知可接受行为，见反馈 §2.4）。
