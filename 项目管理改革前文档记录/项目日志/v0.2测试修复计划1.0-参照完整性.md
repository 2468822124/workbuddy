## 3. 调试过程（⑧ FK 根因）

初始 ⑧ 用例（行 `parent:a1b2c3d4e5f678` 指向项目 todo id）失败：`generatedCount=0` 但 planDate 未更新。临时 probe spec 定位：`synced:false, error:"FOREIGN KEY constraint failed"` —— sync 内部异常被 catch 吞掉返回 synced:false（计数全 0）。

**根因**：tasks.parentTaskId 自引用 FK（`REFERENCES tasks(tid)`，规格 DDL 原文）。§3.7 行 parent 指向**项目 todo id**（非 tasks.tid）→ upsert 时 FK violation。

**修复**：§3.7 复用判据改按规格原文（同 content + projectId 非空 + 未安排），不依赖行内 parent 字段；行内 parent 字段保留给任务链（tasks.tid 自引用）。「写 ref 指向项目任务」未落地（记录偏差：行 parent=项目 todo id 撞 FK；且 ref 指向项目 todo id 时规则0 解析 tasks 查无该 tid → 误标「来源已删」；本期只建复用机制，未来「项目任务选入计划」UI 定稿时落地）。
