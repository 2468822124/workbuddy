## 0. 阶段目标

交付一个可启动的 Electron + Vue3 + TS 工程，包含：
- 三层进程结构（main / preload / renderer）与强类型 IPC。
- better-sqlite3 数据层 + 版本化迁移系统 + 完整 Day-1 schema。
- 敏感字段加密（Electron `safeStorage`）。
- 手帐风 `tokens.css` 落地（阶段 0 token 的唯一真相源）。
- 应用外壳：可折叠侧边栏 + 主内容区 + 路由 + 空状态组件 + 首启检测骨架。

## 3. 主进程启动流程

`main/index.ts`：
1. `app.whenReady()` →
2. 初始化 logger（脱敏）。
3. 打开 DB 连接（`db/connection.ts`，DB 文件路径 = `app.getPath('userData')/workbuddy.db`）。
4. 运行迁移（`migrate.ts`，失败 → 进安全模式，见 §9）。
5. 创建主窗口（`window.ts`：1200×800，最小 720×520， preload）。
6. 注册 IPC handlers。
7. 加载 renderer（dev: `localhost`，prod: `file://`）。

## 5. 数据库 Schema（迁移 `0001_init.ts`）

> SQLite 无原生 BOOL，用 `INTEGER 0/1`；时间统一 ISO8601 TEXT；ID 用 UUID v4（`crypto.randomUUID()`）。

```sql
CREATE TABLE IF NOT EXISTS __schema_migrations (
  version INTEGER PRIMARY KEY,
  appliedAt TEXT NOT NULL
);

-- ===== Day-1 主表 =====
CREATE TABLE IF NOT EXISTS projects (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  status TEXT NOT NULL DEFAULT 'active',  -- active|paused|done|dropped
  description TEXT,
  color TEXT,                             -- 分类色 key（work/learn/health/read），前瞻
  isDeleted INTEGER NOT NULL DEFAULT 0,
  deletedAt TEXT,
  createdAt TEXT NOT NULL,
  updatedAt TEXT NOT NULL
);

CREATE TABLE IF NOT EXISTS todos (
  id TEXT PRIMARY KEY,
  content TEXT NOT NULL,
  status TEXT NOT NULL DEFAULT 'todo',    -- todo|done
  planDate TEXT,                          -- 'YYYY-MM-DD'
  projectId TEXT REFERENCES projects(id) ON DELETE SET NULL,
  isDeleted INTEGER NOT NULL DEFAULT 0,
  deletedAt TEXT,
  completedAt TEXT,
  createdAt TEXT NOT NULL,
  updatedAt TEXT NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_todos_plan ON todos(planDate) WHERE isDeleted=0;
CREATE INDEX IF NOT EXISTS idx_todos_project ON todos(projectId) WHERE isDeleted=0;

CREATE TABLE IF NOT EXISTS settings (
  key TEXT PRIMARY KEY,
  value TEXT NOT NULL,                    -- 敏感值= safeStorage 密文(base64)
  isEncrypted INTEGER NOT NULL DEFAULT 0,
  updatedAt TEXT NOT NULL
);

-- ===== 前瞻表（建表，Day-1 不写业务逻辑）=====
CREATE TABLE IF NOT EXISTS inboxes (
  id TEXT PRIMARY KEY, content TEXT NOT NULL,
  isProcessed INTEGER NOT NULL DEFAULT 0, processedType TEXT, processedAt TEXT,
  createdAt TEXT NOT NULL
);
CREATE TABLE IF NOT EXISTS plans (
  id TEXT PRIMARY KEY, date TEXT, type TEXT, content TEXT,
  generatedTodoIds TEXT, templateId TEXT, createdAt TEXT NOT NULL
);
CREATE TABLE IF NOT EXISTS templates (
  id TEXT PRIMARY KEY, name TEXT, type TEXT, content TEXT, isDefault INTEGER DEFAULT 0
);
CREATE TABLE IF NOT EXISTS reviews (
  id TEXT PRIMARY KEY, date TEXT, type TEXT, content TEXT, linkedProjectIds TEXT
);
CREATE TABLE IF NOT EXISTS notes (
  id TEXT PRIMARY KEY, type TEXT, title TEXT, content TEXT, linkedNoteIds TEXT,
  isDeleted INTEGER NOT NULL DEFAULT 0, createdAt TEXT NOT NULL
);
CREATE TABLE IF NOT EXISTS books ( id TEXT PRIMARY KEY, title TEXT, author TEXT, status TEXT );
CREATE TABLE IF NOT EXISTS workout_logs (
  id TEXT PRIMARY KEY, type TEXT, durationMin INTEGER, distanceKm REAL, feeling TEXT, createdAt TEXT NOT NULL
);
```
迁移执行器：读取 `0001_init.ts` 等按版本号顺序执行，`PRAGMA journal_mode=WAL;` 并在事务中建表 + 写 `__schema_migrations`。

## 6. 敏感字段加密（`lib/crypto.ts`）

使用 **Electron `safeStorage`**（Windows 走 DPAPI，OS 级密钥，无需自管 key）：
```ts
// 伪代码
import { safeStorage } from 'electron';
export function encrypt(plain: string): string {
  if (!safeStorage.isEncryptionAvailable()) throw new Error('SAFE_STORAGE_UNAVAILABLE');
  return safeStorage.encryptString(plain).toString('base64');
}
export function decrypt(b64: string): string {
  return safeStorage.decryptString(Buffer.from(b64, 'base64'));
}
```
- 仅 `settings.isEncrypted=1` 的值走加解密（当前只有 `llmApiKey`）。
- `settingsRepo.set('llmApiKey', v)` 时加密入库；`get` 时解密返回。
- **密文永不进日志**（见 §7）。

## 9. IPC 契约（`shared/ipc.ts`）

强类型通道 + 统一错误信封：
```ts
// shared/ipc.ts
export const IPC = {
  SETTINGS_GET: 'settings:get',
  SETTINGS_SET: 'settings:set',
  DB_HEALTH: 'db:health',
  APP_FIRST_LAUNCH: 'app:isFirstLaunch',
} as const;

export type Result<T> =
  | { ok: true; data: T }
  | { ok: false; error: { code: string; message: string } };
```
- 主进程每个 handler 返回 `Result<T>`；渲染层 `useApi()` 解包，失败抛/提示。
- preload 用 `contextBridge.exposeInMainWorld('api', {...})`，方法签名带类型，渲染进程通过 `window.api` 调用并有 IDE 类型提示。
- **本阶段实现**：`settings:get(key)`、`settings:set(key,value)`（敏感键自动加解密）、`db:health()`（返回 `{ok, schemaVersion, readonly}`）、`app:isFirstLaunch()`。

错误降级基座：DB 损坏/锁定时 `db:health()` 返回 `readonly:true`，渲染层进入「安全模式」横幅（Phase 1 仅占位条）。

- 禁硬编码密钥；禁日志输出业务明文/apiKey；禁业务数据上传云端。
