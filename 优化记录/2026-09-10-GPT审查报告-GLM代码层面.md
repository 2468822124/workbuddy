**现象**：

**根因**：该包不在 `devDependencies`，Prompt 禁止 npm install

**影响面**：
1. 无法生成覆盖率报告（`coverage/index.html`、`coverage-summary.json`）

3. **CI 的 coverage 步骤会失败**

**处置建议**：
需用户/GPT 授权执行 `npm i -D @vitest/coverage-v8`（依赖变更，超出本次 Prompt 边界）。

**优先级**：P1-高（阻断覆盖率功能，但不影响其他门禁）

### P2【环境偏差】本机 Node v22.16.0 与声明版本 20.x 不一致

**现象**：
```bash
check-env.sh
❌ Node.js 版本不匹配！要求: 20.x，当前: v22.16.0
```

**影响**：
- 本机以 22.16.0 运行全部 404 测试与构建均通过
- npm 默认不对 engines 报错（仅警告），本地命令不受阻
- 版本偏差可能导致未知兼容性风险

**需决策**：
1. **以声明（20.x）为准**：本机需换 Node
2. **以本机（22.x）为准**：需改 `.nvmrc`/`engines`/ci.yml/check-env.sh` 四处口径

**优先级**：P2-中（需用户明确版本口径）
