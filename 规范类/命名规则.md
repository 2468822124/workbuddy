# 命名规则（WorkBuddy 工程）

> **维护**：GLM+DS 创建并持续维护；每次修改标注实际执行者。GPT 审查时据此核对。

| 对象 | 约定 | 示例 |
|---|---|---|
| 目录 | kebab-case | `src/main/db/repositories/` |
| 文件 | kebab-case（特殊：Vue 组件、类型文件可 PascalCase） | `settings-repo.ts`、`AppSidebar.vue` |
| Vue 组件 (文件名) | PascalCase | `BaseCard.vue`、`AppLayout.vue` |
| Vue 组件 (模板使用) | PascalCase | `<BaseCard />` |
| 组合式函数 (composable) | `use` 前缀 + camelCase | `useApi.ts`、`useTodos.ts` |
| 常量 | UPPER_SNAKE_CASE | `IPC_CHANNELS`、`DEFAULT_RSS_SOURCES` |
| 变量/函数 | camelCase | `getDb()`、`findByProject()` |
| 类型/接口 | PascalCase | `Todo`、`Project`、`Setting` |
| 枚举成员 | PascalCase | （当前无枚举，如需用 PascalCase 值） |
| IPC 通道 | `domain:action`（camelCase） | `settings:get`、`db:health` |
| 数据库表 | snake_case | `todos`、`workout_logs` |
| DB 字段 | camelCase（与原始定义一致） | `planDate`、`projectId`、`isDeleted` |
| CSS 类 | kebab-case | `.todo-row`、`.nav-item` |
| CSS 变量 | `--kebab-case` | `--bg-app`、`--text-strong` |
| 迁移文件 | `{4位序号}_{描述}.ts` | `0001_init.ts`、`0002_add_tags.ts` |
| 路径别名 | `@/` (renderer), `@shared/` (全局) | `@/components/AppIcon.vue` |

## 规则
1. **禁止拼音**。所有标识符用英文（或业界通用缩写如 `db`、`ipc`、`api`）。中文仅允许在 UI 文本/注释中出现。
2. **禁止单字母**（除循环变量 `i`/`j` 和泛型 `T`/`K`/`V`）。
3. **Repository 命名**：`{entity}Repo`，如 `todoRepo`、`projectRepo`。
4. **IPC Handler 文件**：`{domain}.ipc.ts`，如 `settings.ipc.ts`。
